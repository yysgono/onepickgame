원픽게임 v78 — 헤더 로고와 VS 표시 이미지 최적화

적용 기준: v76까지 적용하고 v77 시작 순서는 되돌린 현재 프로젝트.
v78은 앱 시작 순서나 광고 설정을 바꾸지 않습니다.

적용 방법
1. ZIP을 프로젝트의 같은 경로에 덮어쓰세요.
2. public/ui 폴더의 WebP 이미지 두 개도 반드시 함께 넣으세요.
3. 최신 소스로 새로 빌드하고 전체 결과를 배포하세요.
추가 SQL이나 패키지 설치는 필요 없습니다.

용량
기존 onepick2.png: 329,280바이트 → 표시용 로고: 30,162바이트 (240×135)
기존 vs.png: 594,842바이트 → 표시용 VS: 27,296바이트 (224×191)
합계 924,122 → 57,458바이트: 약 93.8% 감소.
같은 두 파일이 모두 요청되는 방문 기준이며 전체 사이트 전송량 93.8% 감소라는 뜻은 아닙니다.

변경 범위
- 실제 헤더 및 중복 헤더 모듈의 기본 로고 URL.
- 서버 홈 셸의 로고 URL.
- 월드컵 홈/카테고리/라운드 선택 페이지의 VS URL.
- 화면의 CSS 표시 크기, 위치, 비율은 유지합니다.
- 원본 비율을 유지해 축소한 뒤 무손실 WebP로 저장했습니다.
- VS의 투명 배경을 유지합니다.
- 기존 public/onepick2.png와 public/vs.png는 삭제하거나 덮어쓰지 않습니다.
- 후보 사진, 후보 정보, 통계, 로그인, DB, 메타 태그는 변경하지 않습니다.

검증
- 축소 원본과 WebP를 디코딩한 RGBA 픽셀 값이 정확히 일치함을 확인.
- VS 알파 채널 보존 확인.
- 이미지 시각 확인 및 전체 React 프로덕션 빌드 성공.
- 두 이미지가 빌드 폴더에 동일하게 포함되는지 확인.
- 홈 페이징, 화면별 코드 분리 및 16개 언어 홈 SEO 검사 통과.
- 실제 운영 배포나 배포 후 모바일 LCP/CLS 측정은 수행하지 않았습니다.
- 운영 DB 사이트맵 생성을 포함한 전체 npm 빌드 과정은 실행하지 않았습니다.

배포 후 확인
홈의 로고/VS와 카테고리/라운드 선택 화면의 VS가 정상 표시되는지 확인하세요.
PageSpeed 모바일을 같은 주소에서 다시 측정해 이미지 전송량과 FCP/LCP/CLS를 비교하세요.
이 변경은 전송량 개선이며 모바일 첫 화면 7초 지연 전체를 해결한다고 보장하지 않습니다.
