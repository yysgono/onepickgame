OnePickGame v150.1 — 화면 언어 4개 추가 / 수정 파일만

마지막으로 첨부한 “onepickgame - 복사본(2).zip”을 기준으로 만들었습니다.

재확인 후 보완한 버전입니다. 이전 v150 ZIP 대신 이 ZIP 하나를 사용하세요.
- 새 UI 언어에서 퀴즈·티어표를 만들 때 기본 콘텐츠 언어가 기존 영어로 유지되도록 수정했습니다.
- 새 언어 게시판의 서버 첫 화면과 브라우저 화면이 같은 영어 콘텐츠를 조회하도록 맞췄습니다.

적용 방법
1. 현재 사이트 소스 폴더를 복사해 백업합니다.
2. 이 ZIP 안의 src, scripts, tests 폴더와 루트 파일들을 기존 프로젝트의 같은 위치에 덮어씁니다.
   폴더를 통째로 삭제하거나 교체하지 말고, 안의 파일을 합쳐서 덮어쓰세요.
3. 기존과 같은 방법으로 빌드하고 배포합니다. SQL은 실행하지 않습니다.
4. 배포 미리보기에서 헤더의 Italiano / Polski / Nederlands / Čeština를 선택합니다.
   홈 → 월드컵 → 퀴즈 → 티어표 → 랜덤뽑기와 가입약관 링크를 확인하세요.
   로그인과 게임 완료도 한 번씩 확인한 후 운영 배포하세요.

변경 내용
- 이탈리아어, 폴란드어, 네덜란드어, 체코어 메뉴와 화면 문구 추가.
- 영어를 기준으로 가입·로그인, 약관·개인정보처리방침, 게임 인터페이스 문구 번역.
- 새 언어의 주소, 초기 번역 로딩, 뒤로 가기, 검색용 페이지 연결.
- 블로그 글은 번역하지 않습니다. 새 4개 화면 언어에서는 기존 영어 글을 보여줍니다.
- 콘텐츠 언어 선택지는 기존 상태를 사용합니다. 새 UI 언어에서 게시판·문의 작성 기본 콘텐츠 언어는 영어입니다.

유지한 내용
- 기존 16개 언어 번역.
- DB의 게임 제목·후보·퀴즈 문제·블로그 본문.
- 이미지 변환 차단 관련 코드와 통계 기능.
- 블로그 오늘 조회수 목록의 기본 접힌 상태(첨부본에 이미 반영됨).
- 기존 의존성 버전. 새로운 번역 API나 유료 서비스를 연결하지 않았습니다.

확인한 범위
- 프로덕션 프런트엔드 빌드.
- 4개 언어의 번역 키·치환 문구·숫자 제한, 화면 이동, 약관, 퀴즈, 랜덤뽑기 검사.
- 기존 언어 번역 원본 대조와 이미지 회귀 검사.
- 자세한 검증 명령은 VERIFY-v150.md에 있습니다.

실제 운영 계정으로 로그인하거나 운영 DB에 저장하는 검사는 하지 않았습니다.
모든 환경에서 오류가 전혀 없다는 보장은 할 수 없습니다.
문제가 있으면 1번에서 백업한 소스를 복원하고 다시 배포하면 됩니다.
배포한 뒤에 사이트를 추가로 수정했다면 이 패치를 무조건 덮어쓰지 말고 변경 내용을 먼저 비교하세요.

이 ZIP에는 전체 사이트, DB, .env, 비밀번호, API 키 파일이 들어 있지 않습니다.
