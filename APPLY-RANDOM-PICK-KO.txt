OnePickGame 랜덤 뽑기 v5 — 변경 파일 묶음
기준 GitHub main: e540d9074954dacf988ca3d12be98e23eec01d7f

1. 기존 프로젝트를 백업한 뒤 ZIP 안의 파일을 같은 경로에 덮어쓰세요.
전체 프로젝트가 아닌 누적 변경 파일입니다. 다른 최신 로컬 수정이 있으면 먼저 비교하세요.
package.json/package-lock.json 변경이나 새 운영 의존성 설치는 필요 없습니다.

2. Supabase SQL Editor에서 SQL을 실행하세요.
이전 랜덤 뽑기 SQL을 이미 적용했다면:
  supabase/20261021_random_pick_modes.sql만 실행합니다.
처음 설치한다면:
  supabase/20261020_random_pick.sql 실행 후
  supabase/20261021_random_pick_modes.sql을 실행합니다.
기존 월드컵/통계는 변경하지 않습니다. 새 SQL은 추첨 방식과 후보 수 제약을 확장합니다.
실패하면 오류를 확인하고 배포를 진행하세요. 운영 DB에 대신 실행한 것은 아닙니다.

처음 설치한 운영자는 Authentication → Users에서 본인 User UID를 확인한 뒤:
INSERT INTO public.random_pick_operators(user_id)
VALUES ('YOUR_AUTH_USER_UUID') ON CONFLICT DO NOTHING;
본인의 실제 UUID로 바꿔 실행하세요. 기존에 등록했다면 다시 할 필요 없습니다.

3. 최신 소스로 새로 빌드하여 기존 방식으로 배포하세요.
이 ZIP에는 build와 node_modules가 없습니다. 오래된 build를 올리지 마세요.
사이트맵을 포함한 npm run build에는 기존 Supabase 환경변수가 필요합니다.
GitHub에 직접 푸시하거나 사이트를 배포하지 않았습니다.

4. 변경 내용
- 랜덤 뽑기 사이트: 넓은 게임 화면, 큰 다색 홈 카드, 접을 수 있는 후보 설정.
- 핀볼: 벽/장애물/후보 간 실제 충돌, 결승선 도착으로 당첨 결정.
- 추첨기: 통 안에서 움직이는 공, 당첨 인원 및 숫자 범위 설정.
- 돌림판: 고정 확률 편집, 나머지 자동 분배, 스탑 후 감속/최종 각도로 결과 결정.
- 카드/슬롯: 사진 카드 가로 이동 연출.
- 주사위: 해적 대신 주사위 1~3개. 기존 해적 주소는 주사위로 이동.
- 제비뽑기: 번호 상자 클릭, 중복 없는 후보 공개.
- 순서 뽑기: 아래에서 위로 달려 도착 순서 기록.
- 팀 나누기: 즉시 다시 뽑기와 별도 다시 설정.
- 사다리: 위/아래 입력, 새 모양, 미리 보기 가림, 개별 경로/스킵/전체 결과.
- 퀴즈: 객관식 질문 옆에 브라우저 번역 안내.
- 다른 게임으로 이동하면 후보 초기화, 이전 후보 불러오기 지원.

5. 범위와 주의
최대 후보 200명, 사다리 2~20명, 주사위 1~3개입니다.
가져온 후보를 제외/추가해도 원본 월드컵은 변경하지 않습니다.
이전 후보는 메모리에 한 목록만 보관합니다. 새로고침하면 사라지고 localStorage를 채우지 않습니다.
방문자는 후보를 편집해 실행할 수 있고, 템플릿 저장/삭제는 등록된 운영자만 가능합니다.
물리 핀볼은 후보별 동일 확률을 보장하지 않습니다.
카드/추첨기는 뽑은 결과를 연출하며, 돌림판은 시작할 때 당첨자를 정하지 않습니다.
일부 새 상세 도움말은 한국어/영어 외 언어에서 영어로 표시됩니다.
모든 그림과 애니메이션은 자체 구현이며 참고 사이트의 이미지/코드를 복사하지 않았습니다.

6. 검증
React production build, 10종 게임 React/JSDOM 동작, 확률 분배/범위/중복 방지,
핀볼 2~200명 물리 시뮬레이션, 사다리 일대일 연결 및 거리 기반 이동,
SQL 반복 적용/권한, 16개 언어 서버 SEO, 기존 홈 페이징/퀴즈 SEO 검사를 수행했습니다.
실제 PC/모바일 브라우저의 시각 검수와 운영 DB 실행은 하지 못했습니다.
로컬 브라우저가 개발 서버에 접속하지 못해 화면 캡처 검증은 미완료입니다.
포함된 tests는 개발 검증용이며 일부는 별도 테스트 의존성이 필요합니다.
