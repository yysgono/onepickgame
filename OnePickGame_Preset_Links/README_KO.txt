적용법
1. 프로젝트를 백업하세요.
2. 이 ZIP의 src 폴더를 프로젝트 루트(package.json이 있는 폴더)에 복사하여 두 컴포넌트를 교체하세요.
3. translations 폴더와 apply-translations.cjs도 프로젝트 루트에 복사하세요.
4. 프로젝트 터미널에서 node apply-translations.cjs 를 실행하세요.
   기존 번역에 16개 언어 패치를 병합하며 번역 원본 .bak 파일을 만듭니다.
   translations/*.json을 기존 translation.json 전체와 교체하지 마세요.
5. 개발 서버에서 결과 화면과 프리셋 링크를 확인하세요.

변경
- 작성자와 날짜를 헤더 하단 왼쪽, 프리셋 이름 링크를 오른쪽에 배치. 좁은 화면에서 줄바꿈.
- 원픽의 월드컵 버튼 아래 같은 프리셋의 다른 티어표 보기 추가.
- source ID 우선, ID가 없으면 저장된 프리셋 이름으로 필터.
- 하단 버튼은 현재 게시물 제외. 작성자 전체를 제외하는 기능은 아님.
- 프리셋 ID와 이름이 모두 없는 항목은 링크와 버튼을 표시하지 않음.
- ID만 있는 과거 게시물은 '원본 월드컵'으로 표시.
- 이름 기준 필터는 동명 프리셋을 구분할 수 없는 기존 데이터 한계가 있음.

검증: 두 컴포넌트 JSX 파싱, 16개 번역 JSON 검사. 실제 DB/브라우저 E2E는 미실행.
