v48 — 개인 목록/로그인 전용 제작 화면 검색 제외

적용 방법 (v47까지 적용한 프로젝트 기준)
1. 이 ZIP을 풀고 파일을 프로젝트의 같은 경로에 덮어쓰세요.
   category-routes.cjs와 quiz-seo.cjs는 프로젝트 최상위에 둡니다.
2. 최신 소스로 새로 빌드·배포하세요. SQL 실행은 필요 없습니다.
3. 배포가 끝나면 네이버 서치어드바이저의 URL 검사에서 아래 주소를 확인하세요.
   https://www.onepickgame.com/en/my-worldcups
   https://www.onepickgame.com/ko/worldcup-maker
   https://www.onepickgame.com/bn/quiz/create
   로봇 메타 태그에 noindex가 표시되면 정상입니다.
4. 이후 네이버가 다시 방문하면 검색 제외가 반영됩니다.
   빠른 확인이 필요하면 위 주소의 수집을 요청할 수 있습니다.
   24개 주소를 모두 수동으로 웹 페이지 검색 제외할 필요는 없습니다.

변경 사항
- 마이 월드컵의 기존 noindex 유지.
- 월드컵 만들기를 서버 HTML 및 React 모두 noindex로 변경.
- 퀴즈 만들기의 기존 noindex 유지, HTTP X-Robots-Tag 헤더 추가.
- 16개 언어 모두 적용. 페이지의 제목/설명과 앱 파일은 유지.
- 서버의 noindex 페이지는 no-store 응답.
- 사이트맵 생성기에서 이 주소들은 이미 제외되어 있어 수정하지 않았습니다.
- 홈페이지, 공개 월드컵/퀴즈 목록, 카테고리, 공개 상세 페이지의 검색 정책은 그대로입니다.
- robots.txt를 추가로 막지 마세요. 검색로봇이 noindex를 읽을 수 있어야 합니다.

참고
- 화면의 설명 누락 진단은 과거 수집 기록일 수 있어, 배포 직후 없어지지 않을 수 있습니다.
- noindex는 검색 제외 설정입니다. 로그인/DB 접근 권한을 대체하지 않습니다.

검증
- 48개 언어별 비공개 화면의 초기 HTML/헤더/설명/canonical/앱 파일/무조회 동작 검사 통과.
- 퀴즈 SEO 15개 테스트 통과 (공개 상세/사이트맵/서버 오류 처리 포함).
- 운영 빌드 통과. 실제 운영 배포는 별도입니다.
