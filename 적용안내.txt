구절판 게임 버튼 / 이름 편집 / 공개 제목 구분 / 이미지 초점

적용
- 최근 게임 후보 수 선택 패치를 적용한 프로젝트를 기준으로 합니다.
- src 폴더를 같은 경로에 덮어쓰고 빌드/배포하세요. 새 패키지 설치나 SQL 변경은 없습니다.
- tests 폴더는 회귀 검사용입니다.

변경
1. 9명 미만일 때 버튼을 두 줄로 나눴습니다.
   첫 줄: 더 고르기 / 남은 칸 랜덤으로 채우기
   둘째 줄: 뒤로 / 바로 9개 고르기
2. 게임의 뒤로/다음/바로 9개 고르기 버튼을 확대했습니다.
3. 편집 화면에서 ‘사진 아래 이름 표시’를 켜면 각 이름이 직접 편집 가능한 입력란이 됩니다.
   평소에는 이름처럼 보이고, 마우스를 올리거나 키보드로 포커스하면 테두리가 나타납니다.
   클릭해 입력한 이름은 미리보기/이미지 다운로드/공개 데이터에 반영됩니다.
   원본 후보 명단의 이름은 바꾸지 않고 각 칸의 이름만 편집합니다.
4. 게임 후보 수 선택 아래 안내문 글씨를 키웠습니다.
5. 후보 검색창에 실제로 적용되는 3px 보라색 테두리와 큰 글씨를 넣었습니다.
6. 미리보기 하단 다운로드/공유/공개 버튼 옆에도 수정 버튼을 추가했습니다.
7. 프리셋의 기본 구절판 제목을 그대로 공개하면 랜덤 구분자 10자리를 덧붙입니다.
   예: 인생 책 이상형 월드컵 · A2D79C3E04
   별도로 바꾼 제목은 그대로 사용합니다. 다만 제목 중복 오류가 발생하면 구분자를 붙여 재시도합니다.
   제목 중복으로 확인되는 오류에만 최대 3회 요청하며, 권한/비밀번호/제한 등의 오류에는 재시도하지 않습니다.
   기존 공개 글의 제목을 바꾸거나 DB의 제목 중복 규칙을 제거하지 않습니다.
   기존 임시저장 중 기본 제목 정보가 없는 경우에는 사용자 제목으로 보존하고 중복 시 재시도합니다.
8. 게임의 후보 이미지/영상 썸네일 초점을 위쪽 15%로 올렸습니다.
   편집한 구절판 칸의 사용자 확대/위치 설정과 다운로드 크롭은 유지합니다.

검증
- 프로덕션 빌드와 CSS 구문/실제 테두리 및 글자 크기 적용 확인.
- 이름 직접 편집, 원본 명단 보존, 기본 제목 여부 추적, 공개 데이터 반영,
  미리보기 표시 및 하단 수정 버튼 동작 확인.
- 기본 제목 구분자, 사용자 제목 유지, Unicode 길이 제한,
  제목 중복 시에만 제한적으로 재시도하고 증명값을 유지하는 검사 통과.
- 비회원 비밀번호 공개 및 회원 기본 제목/중복 재시도 UI 검사 통과.
- 두 줄 버튼 구조, 게임 진행, 기존 후보 드래그/헤더 홈 이동 회귀 검사 통과.
