# 구절판 입력 중 통합 검색

검색어 입력을 약 300ms 멈추면 프리셋과 공개 구절판을 같은 검색어로 갱신합니다. 검색 버튼이나 Enter로 바로 검색할 수도 있습니다. 미완성 한글 자모는 기다리고, 완성된 한글 음절은 Enter 없이 검색합니다. 늦게 도착한 이전 검색 결과와 이전 더보기 결과는 무시하며 요청도 취소합니다.

프리셋은 기존 검색 범위와 30개 더보기를 유지합니다. 공개 구절판은 12개씩 표시하며 카테고리, 인기순·최신순, 더보기를 유지합니다. 검색어를 지우면 기본 목록으로 돌아갑니다. 검색 안내는 지원하는 20개 언어에 반영했습니다.

공개 작품의 제목, 비회원 닉네임, 저장된 후보 이름·번역 이름, 연결된 월드컵 및 템플릿의 번역 제목으로 검색합니다. 기존 공개 목록 RLS를 따르며 삭제·비공개 작품은 제외합니다. 비밀번호 검증값이나 이미지 주소는 검색하거나 반환하지 않습니다. 검색을 위해 이미지 파일을 새로 저장하지 않습니다.

## 적용 순서

1. Supabase SQL Editor에서 `supabase/20261117_search_top_nine_public_boards.sql`을 한 번 실행합니다. 반복 실행해도 됩니다. 이전 공통 월드컵 썸네일 SQL과 별개의 새 검색 함수입니다.
2. ZIP의 소스 파일을 같은 경로에 덮어씁니다. 이전까지 제공한 수정 사항이 적용된 프로젝트를 기준으로 합니다.
3. 프런트엔드를 빌드하고 배포합니다. 새 환경 변수나 키는 필요하지 않습니다.
4. 구절판 홈에서 한국어·영어 검색, 공개 작품, 카테고리·정렬·더보기, 검색어 지우기를 확인합니다.

실서비스 SQL 실행과 배포는 수행하지 않았습니다. SQL 함수는 현재 필드의 부분 문자열을 검사하는 방식입니다. 데이터 규모에 따른 운영 성능은 별도 관찰이 필요하며, 전문 검색 인덱스를 추가한 변경은 아닙니다.

## 검증

- 프로덕션 빌드 성공.
- 훅 테스트: 입력 지연, 한글 조합, 즉시 제출, 이전 응답·페이지 배제, 요청 취소, 초기화 통과.
- SQL 테스트: 번역·후보 검색, 공개 범위 RLS, 삭제·비공개 제외, 정렬·페이지, 안전한 반환 필드, 반복 적용 통과.
- 실제 빌드 번들 한국어·영어 테스트: 버튼 없이 양쪽 목록 검색, 번역 제목, 더보기·정렬, 결과 없음, 지우기 복원 통과.
- 기존 비회원 티어표·구절판 사진 등록, 실패 후 재시도 회귀 검증 통과.
