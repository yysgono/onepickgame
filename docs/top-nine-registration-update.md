# 구절판 등록 및 로그인 복원

- 만드는 화면의 기본 완료 버튼을 ‘등록하기’로 변경했습니다.
- 사이트 후보만 선택한 비회원은 기존 닉네임·비밀번호 등록 절차를 사용합니다.
- 직접 올린 사진이 있는 비회원은 등록 시 ‘나만 보기 / 로그인 / 회원가입 / 계속 편집’ 안내창을 봅니다.
- 회원은 기존 회원 등록 절차로 사진을 업로드하고 공개 게시합니다. 최종 등록 확인 절차는 유지됩니다.
- 로그인·회원가입 전에 사진 데이터, 후보 목록, 배치·확대·위치, 제목, 이름 표시, 출처·카테고리를 브라우저에 저장합니다.
- 이메일 로그인과 Google/NAVER 로그인 완료 후 편집 화면으로 돌아와 복원합니다. 이메일 회원가입은 기존처럼 로그인 화면으로 이어지며, 로그인 완료 시 복원합니다.
- 저장에 실패하면 이동하지 않고 오류 안내와 작성 내용을 유지합니다.
- 로그인 후 자동으로 공개 게시하지 않습니다. 복원된 내용을 확인하고 ‘등록하기’를 누르면 됩니다.
- 20개 지원 언어의 새 버튼, 안내창, 하단 안내를 번역했습니다.

같은 브라우저·같은 사이트에서 사용하는 흐름입니다. 브라우저 데이터를 직접 삭제하거나 다른 기기로 이동하면 로컬 임시 저장을 자동으로 가져올 수 없습니다. 로그인 완료 전 탭을 닫더라도 저장된 현재 초안은 기존 ‘불러오기’로 복구할 수 있습니다.

## 적용
압축 안 파일을 같은 경로에 덮어쓰세요. 새 파일 authDraft.js와 registrationCopy.json도 포함해야 합니다. SQL 실행은 필요 없습니다. 실제 배포나 계정 로그인·공개 게시 작업은 수행하지 않았습니다.

## 확인
프로덕션 빌드 성공. 안내창/나만 보기/계속 편집, 저장 실패 시 이동 차단, 회원가입 이동 전 저장, 복귀 후 복원, 잘못된 복귀 URL 거부, 20개 언어 키 검증 통과. 기존 비회원/회원 게시 및 회원 이미지 업로드 테스트 통과. 실제 빌드 앱의 한국어 홈·영어 템플릿 실행 확인(JSDOM). 실제 소셜 서비스에 로그인하는 종단간 테스트는 수행하지 않았습니다.
