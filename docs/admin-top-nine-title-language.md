# 구절판 열람 통계의 한국어 제목 수정

관리자 통계가 RPC에서 받은 저장 제목을 그대로 표시하던 문제를 수정했습니다. 최근 기록의 중복 구절판 ID를 묶어서 제목과 원본 연결 정보만 읽고, 기존 구절판 목록과 동일한 한국어 제목 처리를 적용합니다. 직접 지정한 제목과 작성자 이름, 열람 순서·반복 기록·조회수는 유지합니다. 제목 정보 조회에 실패해도 통계 자체는 표시합니다.

이 ZIP은 이번 통계 제목 수정에 필요한 파일만 포함합니다. 프로젝트 루트에 같은 경로로 덮어쓰고 프런트엔드를 빌드·배포하세요. 새 SQL이나 DB 데이터 수정은 없습니다. 이전 홈·서버 수정 전체를 포함한 ZIP은 아닙니다.

검증: 영어 저장 제목의 쿠키런 기록 두 건이 한국어 템플릿 제목으로 표시됨, 구절판 ID 중복 조회 방지, 임의 제목/작성자 이름과 조회수 유지, 제목 조회 실패 시 통계 표시, 기존 통계·현지화 검사 통과.
