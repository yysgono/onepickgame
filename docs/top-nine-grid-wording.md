# 해외 3x3 Grid 문구

한국어 ‘최애 구절판 취향표’는 유지하고, 다른 19개 언어의 구절판 홈 제목·소개에 3x3 Grid를 병기했습니다. 영어 제목은 ‘My Top 9 — 3x3 Grid Maker’입니다. 각 언어의 기존 명칭과 사용 안내는 유지했습니다.

템플릿 소개에도 3x3 Grid 형식명을 넣어 검색용 설명에 반영하고, 영어 사이트 홈 소개에도 병기했습니다. 메뉴와 사용자 작성 제목, URL, 가운데 8각형 배치는 그대로입니다.

이전 문구 패치 적용 후 같은 경로에 덮어쓰세요. SQL은 필요 없습니다. 실제 배포는 하지 않았습니다. 20개 언어의 홈·템플릿 서버 HTML 검증을 통과했습니다.
