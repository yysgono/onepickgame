# 티어표 추천 이미지 찾아보기

## 변경
티어표 홈의 내장 편집기에서 ‘내 이미지 추가’ 바로 옆에 ‘추천 이미지 찾아보기’ 버튼을 추가했습니다. 같은 편집기를 쓰는 티어표 만들기 화면에서도 사용할 수 있습니다.

- 누르면 월드컵 제목만 표시하는 목록이 열립니다. 썸네일이나 후보 이미지를 목록에 표시하지 않습니다.
- 제목을 검색할 수 있고, 목록은 30개씩 더 볼 수 있습니다.
- 제목을 선택하면 해당 월드컵의 후보 이미지를 현재 편집기의 미분류 후보 목록에 추가합니다.
- 기존 티어 배치, 사진과 제목을 초기화하지 않습니다. 제목이 비어 있을 때만 선택한 월드컵 제목으로 채웁니다.
- 같은 이미지 URL이나 후보 키가 이미 있으면 중복 추가하지 않습니다. 최대 후보 수는 기존과 동일하게 1,024개입니다.
- 후보 조회 실패 시 편집 내용은 유지하고 창 안에 재시도 안내를 표시합니다. 닫은 창의 뒤늦은 응답은 가져오지 않습니다.
- 새 버튼과 안내는 20개 언어로 번역했습니다. 아랍어 창은 RTL로 표시합니다.

## 적용
압축 파일 안 파일을 같은 경로에 덮어쓴 후 배포하세요. 새 tierList 폴더의 JS, CSS, JSON과 utils/tierRecommendedCandidates.js도 모두 포함해야 합니다.

새 SQL은 필요 없습니다. 기존 티어표에서 사용하는 get_tier_source_catalogue RPC와 공개 worldcups 조회를 재사용합니다. 추가 저장이나 서버 데이터 변경은 기존 티어표 게시 절차를 통해 이루어집니다.

작업 공간 정리 후 GitHub 최신 기본 브랜치를 다시 받아 수정했습니다. 압축에는 이번 변경 파일만 포함했습니다. 실제 사이트에 배포하거나 GitHub에 커밋·푸시하지 않았습니다.

## 검증
프로덕션 빌드 성공. 제목 전용 목록, 다국어 검색, 페이지 확장, 선택 후에만 후보 조회, 오류 후 재시도, 늦은 응답 취소, 중복 제외·1,024개 제한, 안전한 이미지 URL, 초점 복귀, 20개 언어 키 검증을 통과했습니다. 기존 목록 캐시 테스트도 통과했습니다.

실제 빌드된 앱을 JSDOM에서 한국어·영어 티어표 홈으로 실행했습니다. 업로드 버튼 옆의 새 버튼, 이미지 없는 제목 목록, 두 월드컵의 후보 순차 추가, 기존 후보와 사용자 제목 유지를 확인했습니다. 실제 브라우저의 시각 검수와 운영 DB를 사용한 게시 테스트는 수행하지 않았습니다.
