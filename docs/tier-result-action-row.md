# 티어표 결과 상단 버튼 한 줄 정렬

좋아요 → 이미지 다운로드 → X → Threads → Instagram → 링크 복사 → 수정 → 삭제 순서로 상단 버튼들을 한 줄에 표시합니다. 수정·삭제 노출 권한과 각 버튼 동작은 기존 기능을 유지합니다.

- 상단 공유 그룹의 전체 너비·자동 줄바꿈을 해제했습니다.
- 버튼은 가로 크기를 유지하고, 좁은 화면에서는 버튼 행 내부를 가로 스크롤합니다.
- 복사 완료 등 상태 문구는 버튼 아래에 표시합니다.
- 하단 버튼 영역과 다른 페이지의 공유 버튼 스타일은 변경하지 않습니다.
- 모든 언어에 동일하게 적용됩니다.

이 압축 파일의 두 소스 파일을 기존 경로로 덮어쓰고 빌드·배포하세요. 앞서 전달한 추천 박스 업데이트가 적용된 프로젝트를 기준으로 한 추가 수정입니다. 추가 SQL이나 환경변수는 필요 없습니다.

검증: CRA 빌드 성공, 한국어 모바일 너비/영어 PC 너비의 실제 빌드 JS에서 상단 버튼 8개와 가로 배치·공유 그룹 너비·줄바꿈 방지·가로 스크롤 스타일 확인. JSDOM 검증이며 실제 브라우저 픽셀 배치 검증은 포함하지 않습니다. 운영 배포는 하지 않았습니다.
