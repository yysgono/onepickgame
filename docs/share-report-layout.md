# 공유·신고 정렬 및 신고창 수정

공유 버튼 묶음의 자동 좌우 여백 때문에 바깥에 있던 신고 버튼이 오른쪽 끝으로 밀리는 구조를 수정했다. 신고 버튼을 같은 공유 버튼 그룹의 마지막 항목으로 넣고 다섯 버튼을 한 줄의 가운데에 정렬한다. 좁은 화면에서는 가운데 정렬을 유지하며 줄바꿈한다. 복사 완료/Instagram 안내는 그룹 아래 별도 행을 사용한다. 통계 부모 화면이 갱신될 때 공유/신고 하위 컴포넌트를 새 컴포넌트로 취급해 초기화하던 중첩 컴포넌트 구조도 수정했다. 같은 월드컵에서는 상태를 유지하고 월드컵 ID가 바뀌면 초기화한다.

신고 버튼은 공유 버튼과 동일한 높이와 둥근 형태에 연한 붉은색 배경을 사용한다. 신고창은 document.body의 portal로 띄운다. 결과 카드 영역에 transform이 있어도 그 영역에 갇히지 않고 브라우저 화면 전체를 덮는 배경과 중앙 최대 460px 대화상자로 표시한다. 모바일 여백·최대 높이·스크롤을 지원한다.

신고창에 제목/대상 월드컵, 라벨이 있는 입력칸, 글자 수, 닫기/신고 버튼, 성공·오류 표시 스타일을 적용했다. 기존 언어별 문구를 그대로 사용하여 20개 언어에 적용한다. 로그인 확인과 기존 site_suggestions 신고 저장 형식은 유지한다.

키보드 초점은 입력칸으로 이동하고 대화상자 안에 유지한다. Escape·배경 클릭·닫기 버튼으로 닫을 수 있고, 닫으면 원래 버튼으로 초점을 되돌린다. 제출 중에는 중복 요청과 닫기를 막고 완료 후 다시 조작할 수 있다. 별도 SQL이나 키 설정은 필요하지 않다.
