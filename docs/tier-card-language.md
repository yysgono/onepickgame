# 티어표 카드 제목 언어 수정

## 원인

만들기 페이지의 TemplateDiscovery 목록은 저장된 title/title_translations만 표시했고, 결과 추천 목록은 작품 자체의 번역만 확인했습니다. 한국어로 만들어진 기본 제목에는 영어 번역 필드가 없어, 연결된 템플릿에 영어 제목이 있어도 카드에는 한국어가 남았습니다.

## 변경

src/seo/tierCardTitles.js의 공통 규칙을 두 목록에 적용했습니다. 작품에 해당 언어 번역이 있으면 우선 사용합니다. 기본 템플릿 제목으로 저장한 작품은 원본의 tier_preset_title_translations와 title_translations를 대조해 현재 언어 제목으로 표시하고, ` - admin` 같은 작성자 접미사는 유지합니다. 직접 작성한 제목은 템플릿 제목으로 덮어쓰지 않습니다. 해당 언어 번역이 없는 직접 작성 제목은 원문을 유지합니다. 저장된 데이터는 수정하지 않습니다.

원본 제목 메타데이터는 ID를 중복 제거해 일괄 조회합니다. 후보 이미지 전체나 통계를 불러오지 않습니다. 만들기 페이지의 첫 HTML도 같은 규칙으로 출력합니다. 기존 결과 추천 조회수 숨김과 추천 정렬은 유지합니다.

## 검증 및 적용

자동 제목 한국어/영어/일본어 전환, 작성자 유지, 명시적인 작품 번역 우선, 직접 작성 제목 보존, 번역 없음, 메타데이터 일괄 조회와 첫 HTML 검증을 통과했습니다. 기존 구절판 번역 및 같은 템플릿 필터 테스트 통과. 프로덕션 빌드 및 한국어·영어 결과 페이지 빌드 번들 테스트도 통과했습니다. 실제 사용자의 페이지/번역 데이터에 접근해 수정한 작업은 아닙니다.

이전 수정이 적용된 프로젝트에 ZIP의 src 파일들을 같은 경로에 덮어쓰고 서버·프런트엔드를 빌드/재시작·배포하세요. src/seo/templateDiscovery.js는 서버의 첫 HTML에도 사용합니다. 새 SQL·환경 변수는 없습니다. 실서비스 배포는 수행하지 않았습니다.
