# 월드컵 결과 페이지 중복 공유 버튼 제거

ResultPage 상단에 별도로 넣었던 X·Threads·Instagram·링크 복사 묶음을 제거했다. 시작 버튼 아래 통계 영역의 공유·신고 묶음 하나만 유지한다. 공통 페이지 수정이므로 지원 언어 전체에 적용된다.

기존 공유 URL/복사/신고 기능과 결과·통계·후보 이미지 동작은 변경하지 않았다. 선택 페이지에서 플랫폼 버튼을 제거했던 이전 수정도 유지한다.

반영 파일: src/components/ResultPage.js

검증: 최적화 빌드, 한국어·영어 실제 번들에서 공유 그룹이 한 개인지 확인하고 기존 복사 안내·신고창·결과/통계/후보 이미지가 정상인지 확인했다.

새 SQL이나 설정은 필요하지 않으며 실제 운영 서버에 커밋·푸시·배포하지 않았다.
