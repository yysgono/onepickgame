# 원픽게임 상단 쿠팡 배너

## 적용 내용
공지사항 / 커뮤니티 / 건의사항 / 내 콘텐츠 / Blog 보조 메뉴 바로 아래에 가운데 정렬 배너를 넣습니다. 월드컵·티어표·퀴즈·랜덤 뽑기·구절판 모드에 적용됩니다. 관리자와 개인 콘텐츠 화면 등은 제외됩니다.

사용자가 제공한 배너 ID 920431, 추적 코드 AF6207831을 사용합니다. PC는 728×90, 767px 이하 모바일은 320×100입니다. 화면에 맞는 iframe 한 개만 만들고, 그 안에서 제공받은 공식 스크립트를 실행합니다. 부모 페이지에는 쿠팡 스크립트를 중복 삽입하지 않습니다. 크기 전환 시에는 해당 iframe을 교체합니다.

배너 위에는 광고 표시와 쿠팡 파트너스 수수료 안내를 함께 넣었습니다. 네트워크 로딩에 따라 배너와 본문이 밀리지 않도록 영역 높이를 먼저 확보합니다. 현재 아마존 코드가 없어 해외에서는 쿠팡을 실행하지 않고 해당 광고 공간을 비워 둡니다. 아마존 배너를 받으면 이 공간에 연결할 수 있습니다.

## 국가 판단
페이지 언어가 아니라 Vercel이 제공하는 x-vercel-ip-country 요청 헤더를 사용합니다. 한국(KR)에서 접속하면 영어 페이지에서도 쿠팡이 나옵니다. 해외 접속자나 국가를 확인할 수 없는 요청에서는 쿠팡 스크립트를 실행하지 않습니다. 브라우저 위치 권한이나 별도 외부 IP 조회 서비스는 사용하지 않습니다. VPN을 사용하면 VPN의 접속 국가로 판단될 수 있습니다.

/api/visitor-country 경로를 추가했습니다. 국가 응답은 private, no-store로 캐시하지 않아 다른 국가의 응답이 공유되지 않게 했습니다. 로컬 개발에서는 Vercel 헤더가 없으므로 기본적으로 배너가 나타나지 않습니다.

## 적용 방법
압축 파일을 같은 경로에 덮어쓴 뒤 배포하세요. Header.js뿐 아니라 server.js, vercel.json, affiliate-country.cjs, 새 JS/CSS 파일도 함께 적용해야 합니다. SQL은 필요 없습니다.

기존 Google 자동광고 코드는 수정하지 않았습니다. 배포 후 Google 자동광고가 이 배너 바로 옆에 배치된다면 애드센스 미리보기의 ‘제외된 영역’ 설정으로 조정할 수 있습니다. 코드만으로 자동광고 위치가 제외되었다고 보장하지 않습니다.

배포 후 확인:
1. 한국에서 PC와 모바일로 접속해 실제 상품이 나오는지 확인합니다.
2. 광고와 제휴 안내가 보이는 화면을 캡처하여 쿠팡 파트너스 활동 페이지의 스크린샷으로 등록합니다.
3. 해외에서는 쿠팡 광고가 나오지 않는지 확인합니다.
4. 추적·클릭·실적은 쿠팡 파트너스 리포트에서 확인합니다.

실제 배포·광고 클릭·구매·수익 집계 테스트는 수행하지 않았습니다. 아마존 제휴 코드는 아직 연결하지 않았습니다.

## 검증
프로덕션 빌드 성공. 국가 헤더 검증과 비캐시 응답, Vercel 경로 연결, KR/해외/미확인 분기, PC·모바일 단일 iframe 전환, 수수료 안내, 국가 조회 재사용 테스트 통과. 실제 빌드 앱을 JSDOM에서 실행하여 한국어 PC 및 영어 모바일 페이지에서 보조 메뉴 바로 다음에 각각 728×90과 320×100 iframe이 하나만 표시됨을 확인했습니다. 쿠팡 서버의 실제 광고 스크립트를 실행하여 광고를 노출한 검증은 아닙니다.
