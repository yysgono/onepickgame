# 결과 아래 원본 월드컵 박스 크기 조정

티어표·구절판 결과의 result-source-worldcups에만 컴팩트한 크기를 적용했습니다. 바깥 박스 최대 560px, 사진 카드 최대 420px이며 좁은 화면에서는 화면 너비에 맞춰 줄어듭니다. 기존 카드 max-width:100%가 최대 460px 규칙을 덮어써 결과 박스 전체 너비로 늘어나던 부분을 수정했습니다.

제목은 데스크톱 28px, 모바일 24px로 키웠습니다. 결과 카드의 VS 문자를 기존 홈의 /ui/vs-badge-v78.webp 이미지로 교체했습니다. 데스크톱 88px, 모바일 72px이며 흰색·어두운 그림자를 더해 사진 위에서도 구분되게 했습니다. 만들기 페이지 등 기존 카드의 표시 방식은 유지합니다.

프로덕션 빌드, git diff --check, 실제 빌드 번들의 한국어·영어 티어표/구절판 결과 검사 통과. 저장된 후보 이미지 2장과 VS 배지 1개, 원본 링크와 중복 문구 없음, 티어표 추천·댓글 순서, JavaScript 오류 없음을 확인했습니다. 실제 브라우저 시각적 검증은 별도로 수행하지 않았습니다.

이전 결과 페이지 원본 카드 수정이 적용된 프로젝트에 ZIP의 src 및 public 파일을 같은 경로에 덮어쓰고 빌드·배포하세요. 새 SQL·환경 변수는 없습니다. 실서비스 배포는 수행하지 않았습니다.
