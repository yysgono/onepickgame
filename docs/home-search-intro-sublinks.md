# 홈 소개문 제공 — 카드 검색 표시 제한 해제

이 수정본은 앞선 홈 소개문/서브링크 유도 패키지를 대체한다.

- 홈 meta description에는 사이트 소개문을 유지한다. 한국어: 원픽게임에서 이상형 월드컵과 퀴즈를 즐기고, 티어표와 최애 구절판 취향표를 만들거나 랜덤 뽑기를 해보세요.
- 같은 소개문을 실제 홈 본문에도 제공한다. 월드컵 모드 설명(modeIntro)은 별도로 유지하여 화면에 같은 문구를 반복하지 않는다. 기존 20개 언어에 적용한다.
- 서버 첫 HTML의 개별 월드컵 카드와 React 홈의 카드/최근 생성·최근 플레이 목록에서 data-nosnippet과 rel="nosublink" 제한을 제거했다. 카드 본문을 검색 설명 후보로 쓸 수 있고 개별 링크도 서브링크 후보에서 인위적으로 제외하지 않는다.
- 헤더의 퀴즈·티어표·랜덤 뽑기·구절판 링크와 카드 클릭 동작은 유지한다. 개별 상세 페이지의 내용·주소·색인 정책·사이트맵은 변경하지 않는다. 헤더의 기존 개인정보/보조 메뉴 설정은 이번 변경 대상이 아니다.

소개문을 제공하는 방식으로 검색 설명을 유도한다. 카드 내용을 배제하여 소개문을 강제하지 않는다. 검색어에 따라 검색엔진이 후보 이름 등 다른 본문을 고를 수 있고, 소개문/서브링크 노출이나 순서는 고정할 수 없다. 배포 직후 검색 결과에 즉시 반영되는 것도 아니다.

검증: 20개 언어의 서버 HTML 소개문/단일 description/주요 메뉴·카드 링크/제한 해제, 실제 한국어·영어 프로덕션 번들의 최근 목록 제목, 최적화 CRA 빌드, git diff --check.

추가 SQL·키 설정은 필요 없다. 로컬 수정이며 운영 배포나 검색엔진 수집 요청은 실행하지 않았다.
