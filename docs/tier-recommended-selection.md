# 티어표 추천 후보 선택 · 24명씩 더보기

## 동작
‘내 이미지 추가’ 옆의 ‘추천 이미지 찾아보기’를 누르면 기존처럼 월드컵 제목 목록을 표시합니다. 제목을 선택하면 바로 추가하지 않고 후보 선택 화면을 엽니다.

- 처음에는 아무 후보도 체크하지 않습니다.
- 후보 사진이나 체크박스를 눌러 원하는 후보를 선택합니다.
- ‘전체 선택’은 해당 월드컵의 모든 후보를 선택합니다. 검색으로 숨겨졌거나 더보기 전이라 아직 표시되지 않은 후보도 포함합니다.
- ‘전체 해제’는 모든 체크를 해제합니다.
- ‘선택한 후보 가져오기’는 체크한 후보만 현재 티어표에 추가합니다.
- 후보 이름 검색과 월드컵 목록으로 돌아가기를 지원합니다.
- 선택 화면은 24명씩 표시하고 ‘더보기’를 누를 때마다 24명씩 늘어납니다.
- 가져온 뒤 티어표 편집기의 후보칸도 24명씩 표시합니다. 기존 16명/80명 기준을 모두 24명으로 통일했습니다.
- 기존 이미지·티어 배치·작성 제목 유지, 중복 이미지 제외, 최대 1,024명 제한은 유지합니다.
- 새 버튼과 설명은 20개 언어에 적용했습니다.

## 적용
압축 안 파일을 같은 경로에 덮어쓴 뒤 배포하세요. 이전 ‘추천 이미지 찾아보기’ 패치도 포함합니다. 새 SQL은 필요 없습니다. 기존 get_tier_source_catalogue RPC를 사용합니다. 실제 배포와 GitHub 푸시는 수행하지 않았습니다.

## 검증
프로덕션 빌드 성공. 제목 목록·검색·페이지 추가, 후보 선택 전 이미지 미조회, 선택 화면의 24/48/49명 표시, 미표시 후보를 포함한 전체 선택, 전체 해제, 체크한 2명만 가져오기, 실패 후 재시도, 닫은 창의 늦은 응답 무시, 기존 중복·상한 처리, 20개 언어 검증을 통과했습니다.

실제 빌드 앱을 한국어·영어 티어표 홈으로 실행(JSDOM)해 50명 중 체크한 후보 가져오기, 후보칸 24→48명 더보기, 다른 월드컵에서 후보 추가 후 24→48→51명 표시, 이전 후보와 사용자 제목 유지를 확인했습니다. 실제 브라우저 시각 검수 및 운영 DB 게시 테스트는 수행하지 않았습니다.
