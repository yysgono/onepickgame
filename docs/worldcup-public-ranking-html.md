# 월드컵 결과의 첫 HTML에 공개 순위표 제공

## 적용 내용

`worldcup-view-routes.cjs`가 result/stats 페이지를 렌더링할 때 기존 `get_winner_stats` RPC를 전체 기간(`p_from:null, p_to:null`)으로 읽고, JavaScript 실행 전 HTML에 상위 10명의 공개 통계를 넣는다. 별도 SQL·DB 변경이나 새 API 키가 필요하지 않다.

표에는 순위, 후보명, 우승 횟수, 우승률, 대결 승리 수, 대결 수, 대결 승률을 표시한다. 기존 StatsPage와 같은 기본 순서를 따른다:

1. 우승 횟수 내림차순
2. 우승률 내림차순
3. 대결 승리 수 내림차순
4. 대결 승률 내림차순
5. 모든 값이 같으면 RPC 응답의 기존 순서

우승률 = win_count / total_games × 100 (소수점 한 자리), 대결 승률 = match_wins / match_count × 100 (기존 UI처럼 정수 반올림). 분모가 0이면 '-'를 표시한다. 삭제된 후보는 현재 후보 목록으로 거르고, 현재 후보명/저장된 언어별 번역을 우선한다. 개인별 집계나 사용자 식별 정보는 HTML에 출력하지 않는다.

지원하는 20개 언어 모두 표 제목·기준·조회 상태·확인 시각 문구를 제공한다. 표의 지표 이름은 기존 화면의 `statsTableLabels.json`을 재사용한다. 시간은 DB 최종 수정 시각으로 가장하지 않고, 응답 통계를 확인한 시각(UTC)으로 표시한다.

## 기존 동작 보존

- result/stats 주소, canonical, 기존 리다이렉트, 사이트맵을 변경하지 않았다.
- OG/공유 썸네일 선택 로직과 React 결과·통계·후보 이미지 코드를 변경하지 않았다.
- 경기 진행 match 페이지는 기존 noindex와 no-store를 유지하며 통계 RPC를 추가 호출하지 않는다.
- 집계를 읽기만 하며 우승 기록/조회수 등을 쓰지 않는다.
- 서버 표는 숨긴 검색 전용 텍스트가 아니라 첫 화면에서 읽을 수 있는 HTML이다. React가 로드되면 기존 결과·통계 화면이 이를 대체한다.

## 오류·캐시 처리

통계 RPC의 추가 대기 시간을 3.5초로 제한한다. 통계 요청과 기존 앱 셸 읽기는 병렬로 처리한다. 오류·잘못된 응답·시간 초과 시 페이지의 제목/설명/후보와 앱 스크립트는 정상 제공하고 통계 일시 불가 문구를 표시한다. 오류를 조회수 0이나 임의 순위로 바꾸지 않는다. 이런 실패 응답은 no-store로 하여 CDN이 오류 상태를 오래 저장하지 않게 한다.

정상 응답은 기존 CDN 정책(기본 5분, 재검증 중 이전 응답 최대 1시간 제공)을 유지한다. 따라서 첫 HTML의 스냅샷은 브라우저에서 새로 조회하는 최신 화면 값과 갱신 시점이 다를 수 있다. 기간·회원 필터·사용자 선택 정렬은 기존 브라우저 화면에서 적용한다. 공개 누적 기본 순위만 첫 HTML에 넣는다.

통계 API가 정상적으로 빈 배열을 반환하면 아직 통계가 없다는 문구를 표시한다. 중복 후보 집계·음수/유효하지 않은 카운트는 정상 순위로 출력하지 않는다.

## 반영 파일

필수: `worldcup-view-routes.cjs`, `worldcup-public-stats.cjs`, `src/seo/worldcupPublicStatsCopy.json`.
기존 파일에 더해 새 helper와 JSON도 함께 반영한 후 기존 방식으로 서버를 배포한다. 이 패치에는 별도 SQL이 없다. 이전 구절판 조회수 패치 SQL과는 관계없다.

이번 작업은 로컬 소스 수정 및 검증까지이며, 실제 운영 서버에 커밋·푸시·배포하거나 DB를 변경하지 않았다.

## 확인 결과

- `node --check worldcup-public-stats.cjs`, `node --check worldcup-view-routes.cjs`
- `node tests/worldcup-public-stats.cjs`: 실제 StatsPage의 정렬 코드를 실행해 순서 일치 확인. 20개 언어, 상위 10개, 번역/삭제된 후보, 소수점·분모 0, 공개 필드만 출력, HTML 이스케이프, 빈 통계·오류·시간 초과, 기존 head와 앱 스크립트 보존.
- `node tests/worldcup-public-stats-route.cjs`: 실제 Express HTTP 라우트에서 20개 언어 result/stats 및 Vercel rewrite 요청, 캐시/오류/404/경기 중 무조회 확인.
- `node tests/worldcup-public-stats-production.cjs PATH_TO_BUILD`: 실제 한국어·영어 React 프로덕션 번들에서 첫 HTML 순위표를 기존 앱이 대체한 후 실시간 통계와 현재 우승 후보 썸네일이 정상인지 확인. 기존에 빌드한 변경 없는 프런트엔드 번들을 사용했다.
- 기존 통계 백분율, 선택 후보를 포함하는 페이지네이션, 후보 썸네일/영상 관련 회귀 테스트 통과.

자동 검증은 모의 공개 집계 응답을 사용했다. 운영 RPC 읽기 확인도 시도했으나 이 실행 환경의 네트워크 오류로 확인하지 못했다. 운영 반영 후 실제 결과 URL의 페이지 소스에 순위표가 있는지 확인해야 한다. 색인/상위 노출을 보장하는 기능은 아니다.
