# 비회원 PC 사진 등록 (2026-11-16)

## 반영 내용
- 구절판: 선택된 최대 9장의 사진을 공개 등록 시 업로드합니다.
- 티어표: PC에서 가져온 후보는 비회원 기준 누적 최대 50명입니다. 여러 번 추가해도 합산하며, 저장된 후보의 `source: local`도 계산합니다. 사이트에서 불러온 후보는 이 제한에서 제외합니다.
- 비회원은 JPG·PNG·WebP·AVIF 정지 사진을 사용할 수 있습니다. GIF·동영상은 기존 회원 업로드 흐름을 사용합니다.
- 편집 단계에서는 브라우저에 보관하고 등록할 때 JPEG로 압축합니다. 기존 입력 용량 제한을 유지하며, 압축 후 구절판은 장당 512 KiB, 티어표는 장당 1 MiB 이하입니다.
- 기존 닉네임·비밀번호 등록 및 수정·삭제 RPC를 유지합니다. 별도 익명 로그인이나 회원 세션 변경을 하지 않습니다.
- 등록 실패 시 편집 중인 사진을 유지하고 다시 시도할 수 있습니다. 사용자가 브라우저 데이터를 지우거나 탭을 닫아도 무조건 보존된다는 뜻은 아닙니다. 기존 초안 저장을 이용하세요.
- 안내·오류·공유 문구는 지원하는 20개 언어에 반영했습니다.

## 적용 순서 (필수)
1. 기존 비회원 등록 기능이 정상 작동하는 프로젝트에 `supabase/20261116_guest_content_uploads.sql`을 Supabase SQL Editor에서 실행합니다. SQL은 반복 실행할 수 있습니다. 기존 `publish_top_nine_board_v5`, `create_guest_tier_list`, `update_guest_tier_list`와 기존 비밀번호 검증은 대체하지 않습니다.
2. 배포 서버에 `SUPABASE_SERVICE_ROLE_KEY`가 설정되어 있는지 확인합니다. 기존 관리자 기능이 쓰는 서버 전용 변수입니다. 브라우저용 `REACT_APP_*` 변수에 넣지 마세요.
3. 정기 정리를 위해 서버 전용 `CRON_SECRET`을 충분히 긴 무작위 값으로 설정합니다. Vercel Cron 요청의 Bearer 인증에 사용합니다.
4. ZIP의 파일을 기존 프로젝트에 같은 경로로 덮어쓰고 서버와 프런트엔드를 함께 배포합니다. 이 ZIP에는 앞서 수정한 파일의 현재 전체 내용과 필요한 추가 모듈도 포함했습니다.
5. 비회원으로 사진 1장 이상 등록 → 본인 결과 페이지 → 비밀번호 수정·삭제를 확인합니다. 회원 기존 업로드 및 사이트 후보 가져오기도 확인합니다.

이 작업에서는 운영 SQL 실행이나 배포를 하지 않았습니다. 위 설정 없이 프런트엔드 파일만 올리면 사진 등록이 실패합니다. 실제 운영 DB의 기존 비회원 RPC 본문은 이 저장소에 없어 수정하지 않았습니다. 배포 후 해당 기존 RPC와의 연동 확인이 필요합니다.

## 업로드 보호 및 정리
- 전용 공개 이미지 버킷 `guest-content-images`를 생성합니다. 업로드는 서버 중계만 허용하고, 브라우저의 직접 쓰기·수정·삭제는 제한 정책으로 막습니다. 이미지는 공개 등록 기능에 사용하는 공개 URL입니다.
- 파일별 해시·크기·JPEG 헤더·최대 치수를 서버에서 검사합니다. 업로드 경로는 서버가 생성하고 덮어쓰지 않습니다.
- 기본 제한: IP당 시간당 5회 / 하루 20회 / 하루 예약 용량 100 MiB, 전체 하루 300회 / 1 GiB. 취소·실패 시도도 제한에 포함합니다. 같은 IP를 쓰는 여러 사용자도 합산됩니다.
- 원본 IP 대신 서버 비밀값으로 해시한 IP와 만료되는 업로드 티켓을 사용합니다. 업로드 작업 테이블은 일반 사용자에게 공개하지 않습니다.
- 실패·중단 파일은 즉시 삭제하지 않고 정리 대상으로 둡니다. 미완료 티켓은 30분 만료 후 추가 10분, 취소 작업은 10분 유예 후 정리 가능합니다.
- 새 업로드 시작 시 오래된 작업 1개를 정리하고, 매일 04:15 한국 시간 Cron에서 최대 10개 작업을 제한 시간 내 처리합니다. 밀린 작업은 다음 실행으로 넘어갑니다.
- 공개 게시물 및 보관 중인 게시물이 참조하는 파일은 삭제하지 않습니다. 참조 검사와 잠금으로 저장과 정리의 충돌을 방지합니다. 실제 파일 삭제는 Storage API로 수행합니다.
- 전용 버킷 파일을 수동으로 삭제하지 마세요. 기존 회원 버킷과 파일에는 이 정리 작업을 적용하지 않습니다.
