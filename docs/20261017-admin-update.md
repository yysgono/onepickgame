# 관리자 페이지 수정 적용 안내

현재 프로젝트에 ZIP 안의 src 폴더를 같은 위치로 복사하고 덮어쓰세요.
새 파일 src/utils/adminReadApi.js도 반드시 함께 복사하세요.
이 ZIP은 전체 프로젝트가 아니라 관리자 메인·통계 수정 파일만 포함합니다.

## 변경 내용
- 관리자 화면에서 불필요한 전체 월드컵 후보 데이터 중복 조회 제거.
- 관리자 목록을 나누어 조회해 1,000개 초과 시 누락 방지.
- 번역 제목과 ID로 관리 목록 검색 지원.
- 휴지통 복구·영구삭제 후 다른 항목의 미저장 편집값 유지.
- 조회 실패와 실제 0건을 구분하고 재시도 제공.
- 통계 날짜를 한국시간 기준으로 계산하고 완료 수로 표시.

## 적용 순서
1. 위 네 파일을 모두 복사합니다.
2. 기존 배포 방식대로 커밋·푸시하고 배포 완료를 확인합니다.
3. /ko/admin 및 /ko/admin-stats를 확인합니다.

추가 SQL 실행이나 DB 구조 변경은 없습니다. 기존 로그인·RLS 권한을 사용합니다.

## 검증
- 모의 DB 기반 API·화면 테스트 통과.
- 1,000개 초과 목록, 실패 후 재시도, 편집값 유지, 한국시간 날짜 경계 검증.
- React production build 성공.
- 실제 운영 데이터의 복구·삭제는 실행하지 않았습니다.
