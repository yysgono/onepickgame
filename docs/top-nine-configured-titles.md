# 구절판 프리셋의 지정 제목 유지

한국어 제목에서 `구절판`을 `구절판 취향표`로 확장하던 표시용 치환을 제거했습니다. 대시보드에서 설정한 제목을 프리셋 카드, 만들기 페이지 제목, 서버의 첫 HTML/SEO 제목 및 연결된 작품 카드에 그대로 반영합니다. 영어 등 다른 언어 번역 선택 규칙은 유지합니다.

이전에 자동 확장된 제목으로 저장한 작품은 호환용 제목 대조 규칙을 유지해 현재 템플릿 제목을 표시하며 작성자 접미사는 유지합니다. 직접 작성한 제목은 덮어쓰지 않습니다. 메뉴명·일반 소개문에 쓰는 구절판 취향표 문구는 유지합니다.

저장된 데이터나 대시보드 설정은 변경하지 않았습니다. 새 SQL·환경 변수는 없습니다. 이전 수정이 적용된 프로젝트에 ZIP의 src 파일 4개를 덮어쓰고 서버 및 프런트엔드를 빌드/재시작·배포하세요. 서버도 같은 제목 함수를 사용하므로 프런트엔드만 배포하면 최초 HTML 제목이 예전과 다를 수 있습니다. 실서비스 배포는 수행하지 않았습니다.

검증: 지정한 짧은 한국어 제목, 이전 확장 제목의 호환, 작성자·직접 작성 제목 유지, 20개 언어 표시 및 기존 구절판 번역 테스트 통과. 프로덕션 빌드 성공.
