# 구절판 카드·공유 버튼·후보 안내 간격 수정

- 홈의 다른 사람들이 만든 구절판 카드 아래에서 별도로 표시하던 닉네임과 조회수를 제거했다. 제목 안의 기존 작성자 표기와 편집/삭제 권한 버튼은 변경하지 않았다. 인기순 정렬과 조회수 집계 데이터는 유지한다.
- 공통 X·Threads·Instagram·링크 복사 버튼을 글자 16px, 최소 높이 48px, 패딩 12px 22px로 확대했다. 좁은 화면에서는 줄바꿈한다.
- 후보 사진 클릭/두 번 누르기 안내를 후보 초기화 버튼과 같은 줄의 왼쪽으로 올렸다. 긴 번역 문구는 왼쪽 영역 안에서 줄바꿈하며 검색창은 그 아래에 위치한다.
- 공통 컴포넌트에 반영하여 기존 지원 언어 전체에 적용된다. 새로운 SQL이나 설정은 필요하지 않다.

이번 수정은 아래 네 소스 파일에 해당한다.

1. src/components/topNine/PublicBoards.js
2. src/components/TopNinePage.js
3. src/components/topNine/topNine.css
4. src/components/sharing/socialShare.css

기존 갤러리 정렬·공유·등록 후 상세 이동 회귀 검증과 최적화 프런트엔드 빌드를 확인했다. 실제 운영 서버에 커밋·푸시·배포하지 않았다.
