- 설명문에 연보라색 배경과 2px 테두리를 추가했습니다.

## 검증

프로덕션 빌드, 두 JSX 파일 문법 검사 및 git diff --check 통과. 실제 빌드 번들로 한국어·영어 카테고리 화면을 실행해 새 검색창 표시, 입력 검색 요청의 animation 필터 유지, URL 이동 없음, JavaScript 오류 없음을 확인했습니다.
기존 tests/quiz-home-v30.cjs는 변경하지 않은 QuizCategorySections의 최초 카드 수를 5개로 기대하지만 현재 컴포넌트가 4개를 요청하여 실패했습니다. 이번 수정의 카테고리 검색 입력/필터 검증은 별도로 통과했습니다. 실제 브라우저의 시각적 검증은 별도로 수행하지 않았습니다.
