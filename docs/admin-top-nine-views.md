# 관리자 통계 대시보드에 구절판 열람 통계 추가

관리자 통계 페이지(AdminStatsPage)의 콘텐츠별 현황 아래에 별도 구절판 취향표 열람 영역을 추가했다. 기존 등록·나만 보기 완료 통계는 유지한다.

- 누적 조회수: 현재 공개된 top_nine_public_boards.view_count 합계.
- 오늘 열람 수: 기존 top_nine_view_sessions_v2 기록 중 한국 시간 당일 00:00~24:00 범위.
- 아래 최근 30건: 열람 시각 최신순으로 구절판 제목, 해당 구절판 누적 조회수, 열람 시각을 표시한다. 제목을 누르면 공개 결과로 이동한다.
- 기존 탭 세션별 중복 제외 방식은 유지한다. 새 추적 방식을 추가하거나 조회수를 재설정하지 않는다.

## 적용 순서 — SQL 필요

1. 이전 `supabase/20261115_top_nine_view_tracking.sql`을 이미 적용했다면 다시 실행할 필요 없다. 아직 적용하지 않았다면 먼저 실행한다. 이 패키지에 함께 넣었다.
2. 새 `supabase/20261116_admin_top_nine_views.sql`을 Supabase SQL Editor에서 실행한다.
3. 새 컴포넌트 `src/components/AdminTopNineViews.js`와 수정된 `src/components/AdminStatsPage.js`를 함께 반영하고 배포한다.
4. 관리자 통계 대시보드에서 통계 새로고침을 누른다.

새 RPC는 기존 is_top_nine_moderator() 권한 검사와 authenticated 실행 권한으로 보호한다. 일반 회원과 비회원은 이 통계를 읽을 수 없고 방문자 세션 ID도 반환하지 않는다. 기존 조회 이벤트 테이블의 공개 읽기 권한을 열지 않는다.

## 집계 범위와 한계

공개 구절판 결과 페이지를 연 기록이다. 템플릿/만들기 화면, 나만 보기와 비공개 단축 링크는 기존 기록 대상이 아니므로 포함하지 않는다. 누적은 현재 남아 있는 공개 게시물 조회수 합계이고, 삭제된 게시물 및 그 게시물과 함께 삭제된 열람 기록은 제외된다. 삭제 후에도 남는 영구 누적 통계를 새로 만든 기능은 아니다.

과거 조회수만 있고 시각별 이벤트가 없는 경우 누적에는 반영되지만 최근/오늘 목록을 복원할 수는 없다. 상세 이벤트 집계 시작 시각을 화면에 표시한다. 기존 이벤트에는 열람 국가/언어가 저장돼 있지 않으므로 이를 추측하여 표시하지 않는다. 제목은 현재 공개 게시물에 저장된 제목을 사용한다.

통계 SQL 미적용·권한·연결 오류는 오류 안내와 재시도로 표시하며 0회로 오인하게 하지 않는다. 진짜 빈 기록일 때만 0회 및 빈 목록 안내를 표시한다. 다른 대시보드 통계가 실패해도 이 영역은 독립적으로 조회한다.

## 검증

- tests/admin-top-nine-views-sql.cjs: PostgreSQL(PGlite)에서 관리자/일반회원/비회원 권한, 방문자 ID 비노출, KST 날짜 경계, 최근 30건 정렬, SQL 재적용, 기존 조회수·중복 제외 유지, 삭제 제외 확인.
- tests/admin-top-nine-views-ui.cjs: 실제 React 컴포넌트의 숫자·제목 링크·KST 시각·제목 이스케이프·새로고침/재시도·SQL 미적용·잘못된 수치와 진짜 빈 목록 구분 확인. 외부 DB는 모의 응답으로 검증했다.
- 최적화 CRA 빌드와 git diff --check 통과.

실제 운영 DB에 SQL을 실행하거나 커밋·푸시·배포하지 않았다.
