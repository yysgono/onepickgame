# 관리자 대시보드 콘텐츠 순서 변경

최근 기록 영역을 월드컵 → 퀴즈 → 티어표 → 취향표 순서로 배치했다. 최근 댓글은 그 아래에 유지한다.

상단 콘텐츠별 현황 표도 월드컵 → 퀴즈 → 티어표 → 취향표를 먼저 표시하고 기존 랜덤뽑기·블로그 행은 이어서 표시한다. 집계 방식이나 저장 데이터는 변경하지 않았다.

반영 파일: src/components/AdminStatsPage.js, src/components/AdminContentSummary.js.

순서 변경 자체에는 추가 SQL이 필요 없다. 앞선 취향표 열람 기능의 통계 SQL은 그대로 사용한다. 최적화 CRA 빌드 및 git diff --check 확인. 운영 서버에 커밋·푸시·배포하지 않았다.
