# 한국어 검색용 사이트 이름 통일

한국어 페이지의 제목 뒤에 붙는 OnePickGame/One Pick Game을 원픽게임으로 표시합니다. 공용 Seo 컴포넌트와 월드컵 결과·구절판 홈·공개 결과·템플릿·랜덤 뽑기 서버 HTML에 같은 규칙을 적용했습니다. 공용 Seo의 og:site_name과 사이트 구조화 데이터 이름도 한국어로 맞췄습니다.

작성자가 지정한 콘텐츠 제목 본문과 다른 언어 표기는 유지합니다. 헤더 로고의 영문 글자는 이 요청의 제목 접미사와 별개로 그대로 둡니다.

수정 파일을 프로젝트 루트에 덮어쓰고 프런트엔드와 서버를 함께 빌드·배포하세요. 새 SQL이나 환경변수는 없습니다. 검색 결과에 이미 표시된 제목은 검색엔진 재수집 이후 변경될 수 있으며 배포 즉시 반영을 보장하지 않습니다.

검사: 20개 언어 서버 제목·대표 URL·개별/목록 페이지·작성 제목 보존, React 빌드 및 한국어/영어 목록·결과 회귀 검사.
