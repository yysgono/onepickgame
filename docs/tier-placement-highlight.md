# 티어표 후보 배치 선택 박스 강조

후보를 클릭했을 때 나오는 배치 선택 박스에 연보라색 배경, 진한 보라색 2px 테두리, 그림자를 적용했습니다. 제목은 진한 보라색으로 표시하고 긴 후보 이름은 줄바꿈합니다.

S~F 등급 버튼에는 기존 등급별 색상을 채우고 어두운 테두리를 추가했습니다. 마우스를 올리거나 키보드로 초점을 이동할 때 윤곽선이 표시됩니다. 배치 동작과 등급 순서는 유지합니다.

PC·모바일, 위쪽 배치 박스와 후보 영역의 고정 배치 박스에 공통 적용됩니다. 모든 언어가 같은 스타일을 사용합니다.

두 소스 파일을 기존 경로로 덮어쓰고 빌드·배포하세요. 이전에 전달한 누적 업데이트가 적용된 프로젝트 기준입니다. SQL이나 환경변수 변경은 없습니다.
