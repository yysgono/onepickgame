# 구절판 등록 후 상세 페이지로 이동

공개 등록 성공 후 홈으로 돌아가는 대신, 방금 생성된 게시물 ID의 /{lang}/mytop9/{id} 상세 페이지로 이동합니다. 템플릿에서 만들었거나 홈 편집기에서 만들었을 때 모두 적용됩니다.

기존 구절판을 수정·저장한 경우에도 같은 상세 주소에서 최신 게시물 데이터를 다시 읽습니다. 기존 홈 콜백을 실행하지 않으며, ‘홈으로’ 버튼은 사용자가 직접 누를 때 사용할 수 있습니다. 임시 저장은 유지합니다. 나만 보기와 링크 공유의 동작은 이번 변경 대상이 아닙니다.

20개 언어의 현재 페이지 언어에 맞는 상세 주소를 사용합니다. 새 문구나 SQL은 필요 없습니다. 압축 파일을 같은 경로에 덮어쓴 뒤 배포하세요. 실제 배포와 GitHub 푸시는 수행하지 않았습니다.

검증: 20개 언어의 등록 성공 시 상세 주소 이동 및 홈 콜백 미실행, 같은 ID 수정 저장 후 최신 내용 재조회 검증 통과. 기존 로그인·회원가입 임시 저장 및 복원 테스트 통과. 프로덕션 빌드 성공. 실제 운영 DB에서 새 게시물을 작성하는 검증은 수행하지 않았습니다.
