# 원본 월드컵 카드에 홈과 같은 우승 1·2위 사용

- 월드컵 홈의 `getTop2Winners` 선정 규칙을 공통 모듈 `src/utils/worldcupCardPreview.js`로 분리했습니다. 홈과 프리셋의 원본 월드컵 카드가 같은 함수를 사용합니다.
- 누적 우승 횟수 내림차순, 동률이면 대결 승리 횟수 내림차순으로 두 후보를 고릅니다. 완전히 같으면 기존 통계 배열 순서를 유지합니다.
- 연결된 원본 월드컵 한 개에 대해 기존 홈과 같은 공개 `winner_stats`의 후보 ID·우승 횟수·대결 승리 횟수만 한 번 조회하고 합산합니다. 사용자 정보·후보 이미지 풀을 새로 가져오지 않습니다. 기존 제작 화면에 이미 있는 후보 데이터에서 해당 두 이미지 주소를 찾습니다.
- 통계가 없거나 조회에 실패하면 홈처럼 기본 후보 두 장으로 대체해 제작 화면을 유지합니다.
- 기존 이미지 URL을 재사용하며 새 이미지 파일을 서버에 만들거나 저장하지 않습니다. 이미 받은 동일 URL이 브라우저에서 유효하게 캐시되어 있으면 재사용할 수 있습니다. 캐시가 없거나 만료되면 두 파일의 실제 용량만큼 다운로드가 필요합니다. 작은 카드로 표시하는 것만으로 원본 파일이 축소되지는 않습니다.
- 이 변경은 '이 후보로 이상형 월드컵 하기' 카드에 적용됩니다. 구절판 작품 자체의 9칸 미리보기와 템플릿의 등록된 대표 썸네일, 5개씩 넘기기는 유지합니다.

앞선 업데이트가 적용된 프로젝트 기준입니다. 같은 경로로 파일을 덮어쓰고 서버와 프런트엔드를 함께 빌드·배포합니다. 공통 함수 파일을 반드시 포함하세요. 추가 SQL·환경변수는 필요 없습니다. 운영 배포는 하지 않았습니다.

검증: 배포 빌드, 누적 통계 합산·우승/대결 승리 동률·후보 ID 형식·통계 실패 시 기본 이미지·원본 URL 재사용 검사. 기존 템플릿 링크·언어별 작품 제목 검사도 통과했습니다. 이미지별 실제 트래픽과 캐시 적중률은 측정하지 않았습니다.
