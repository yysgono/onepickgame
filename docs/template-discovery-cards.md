# 프리셋 관련 콘텐츠 카드·가로 넘김 (2026-11-17)

## 화면
- 원본 이상형 월드컵: 후보 사진 두 장과 제목이 보이는 카드입니다. 카드 및 제목을 누르면 원본 월드컵 시작 페이지로 이동합니다.
- 같은 주제의 다른 구절판/티어표: 사진 미리보기와 제목을 담은 가로 카드 목록입니다. 구절판은 기존 공개 카드와 같은 구절판 배치·확대/위치 정보를 재사용합니다.
- 관련 템플릿: 홈에서 쓰는 대표 썸네일과 제목으로 카드 목록을 표시합니다. 카드 전체 및 제목을 누를 수 있습니다.
- 두 목록은 최대 12개, 좌우 버튼·가로 스크롤·모바일 터치로 넘깁니다. 아랍어의 이동 방향과 동작 줄이기 설정을 지원합니다. 처음/마지막에서는 해당 방향 버튼을 비활성화합니다.
- 제목은 최대 3줄이며 전체 제목은 마우스를 올리면 확인할 수 있습니다. 작은 화면에서도 카드가 페이지 전체를 옆으로 밀지 않도록 내부에서 스크롤합니다.
- 문구는 20개 언어에 적용했습니다.

## 데이터와 검색용 HTML
- 같은 원본/템플릿 작품을 먼저 조회수순으로 읽고, 부족하면 같은 카테고리 작품으로 채웁니다. 공개 작품만 기존 접근 권한으로 조회합니다.
- 티어표는 기존 `worldcup_tier_preset_cards` 공개 카드 뷰 및 `tier_preset_thumbnails`, 구절판은 기존 추천 RPC와 `top_nine_thumbnails`의 대표 사진을 사용합니다.
- 원본 월드컵 및 대표 이미지가 없는 프리셋은 후보 1~2개의 미리보기만 JSON 필드 투영으로 조회합니다. 추가 카드 조회 때문에 후보 사진 풀 전체를 읽지 않습니다.
- 공개 구절판 작품은 최대 9칸의 저장된 공개 사진·배치 정보만 미리보기에 사용합니다. 이미지 파일은 프런트엔드에서 지연 로딩합니다.
- 첫 HTML에도 실제 링크·제목·이미지 태그를 유지합니다. React가 실행된 후에도 동일한 링크가 카드로 남습니다.
- 메타데이터 추가 조회 제한은 약 3.5초입니다. 실패 시 기존 제작 화면은 유지하고 얻을 수 있는 정보로 카드를 표시합니다. 이미지가 없는 항목은 기본 아이콘을 사용합니다.

## 적용
이전 업데이트가 적용된 프로젝트에 같은 경로로 덮어쓰고 서버·프런트엔드를 함께 빌드하여 배포합니다. 필요한 앞선 내부 링크 파일도 함께 첨부했습니다. 추가 SQL·환경변수·대시보드 재등록은 필요 없습니다. 운영 배포나 운영 DB 변경은 수행하지 않았습니다.

## 검증
- CRA 빌드 통과.
- 실제 빌드 JS를 JSDOM에서 실행: 한국어/영어 구절판·티어표 프리셋에서 원본 사진 2장, 작품/템플릿 카드, 서버 링크 메타데이터 재사용, 첫 HTML 링크 및 최종 색인 허용 상태 유지 확인.
- 별도 UI 검증: 썸네일·구절판 배치, 제목의 상세 링크, 이전/다음 이동 및 끝 상태, 아랍어 스크롤 방향 확인.
- 서버 검증: 대표 썸네일 우선, 공개 원본·작품 연결, 20개 언어, HTML/JSON 안전 출력, 개인·수정 화면 제외 확인.
- 실제 브라우저 픽셀 배치 및 운영 검색 순위 검증은 포함하지 않습니다.
