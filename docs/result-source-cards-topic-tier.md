# 결과 페이지의 원본 월드컵 카드와 같은 주제 티어표

## 변경

- 티어표 결과에서 기존 추천 티어표와 RelatedContentLinks(이 주제로 더 즐기기) 표시를 제거했습니다.
- 댓글 위에 `같은 주제의 다른 티어표` 박스를 하나 배치했습니다. 같은 원본 템플릿/프리셋 작품을 먼저, 같은 카테고리 작품을 다음으로 조회수순 표시합니다. 현재 작품과 삭제된 작품은 제외하고, 관련 없는 전체 인기작으로 채우지 않습니다. 해당 작품이 없으면 빈 박스를 만들지 않습니다.
- 티어표·구절판 결과에 `이 후보로 이상형 월드컵 하기` 원본 카드 박스를 추가했습니다. 구절판 만들기의 Card 컴포넌트와 동일한 표시를 재사용합니다. 제목과 카드 전체를 누르면 원본 월드컵 선택 페이지로 이동합니다.
- 원본 썸네일은 기존 worldcup_card_previews의 저장된 공통 1·2위 이미지를 재사용합니다. 후보 전체나 winner_stats를 가져오거나 순위를 재계산하지 않습니다. 제목 메타데이터만 추가 조회합니다.
- 연결된 원본 월드컵이 없는 작품은 원본 카드를 표시하지 않습니다. 구절판이 여러 월드컵에서 후보를 가져온 경우 최대 9개 원본 카드를 표시합니다. 접근할 수 없거나 삭제된 원본은 제외합니다.
- 새 제목은 20개 언어에 반영했습니다.

## 검증

프로덕션 빌드, git diff --check, 추천 필터 단위 검증 통과. 실제 빌드 번들을 JSDOM에서 한국어·영어 티어표/구절판 결과 4개 경로로 실행했습니다. 원본 카드 링크, 저장된 1·2위 이미지, 카드 내부 중복 안내 없음, 티어표 추천 제목과 댓글 위 위치, 삭제한 관련 링크 박스 없음, JavaScript 오류 없음을 확인했습니다. 별도의 실제 브라우저 시각 검증은 수행하지 않았습니다.

## 적용

이전 수정들이 적용된 프로젝트에 ZIP의 소스를 같은 경로로 덮어쓰고 프런트엔드를 빌드·배포하세요. 새 SQL·환경 변수는 없습니다. 저장된 1·2위 썸네일 표시는 앞서 제공한 worldcup_card_previews SQL이 이미 적용되어 있어야 합니다. 아직 실행하지 않았다면 이전 공통 썸네일 ZIP의 SQL을 먼저 실행하세요. 실서비스 배포·SQL 실행은 수행하지 않았습니다.
