# 관련 카드 5개씩 표시

관련 템플릿과 같은 주제의 다른 구절판/티어표 모두 한 묶음에 최대 5개씩 표시합니다. 이전·다음 버튼은 카드 몇 장만 옆으로 미는 대신 다음 5개 묶음으로 교체합니다. 12개 목록은 5 → 5 → 2개이며 페이지 번호를 함께 표시합니다.

PC에서는 카드 5개가 행 안에 들어가도록 너비를 조절합니다. 작은 화면은 현재 묶음 안에서 터치로 가로 스크롤할 수 있으며, 화살표로 다음 묶음으로 이동합니다. 처음·마지막 이동 버튼, 아랍어 방향, 카드 전체와 제목의 이동 링크를 유지합니다.

## 이미지 및 캐시
- 다음 묶음 카드는 넘기기 전까지 React DOM에 생성하지 않습니다. 서버의 첫 HTML도 각 목록의 첫 5개 이미지·링크만 출력하며, 다음 묶음의 정보는 이미지 요청을 발생시키지 않는 JSON 메타데이터로 전달합니다.
- 현재 묶음 이미지도 기존 지연 로딩을 사용합니다. 페이지를 넘겨도 목록 메타데이터를 다시 요청하지 않습니다.
- 서버에 새 이미지 파일을 저장하거나 복제하지 않습니다. 기존 대표 사진과 공개 작품의 사진 주소를 재사용합니다.
- 작은 카드로 표시하는 것과 작은 이미지 파일을 내려받는 것은 다릅니다. 별도 축소 파일이 없는 항목은 원본 주소를 사용하고, MediaRenderer는 이 프로젝트의 변환 이미지 주소를 원본 주소로 되돌리는 기존 동작도 유지합니다.
- 구절판 카드 하나는 최대 9장의 사진으로 미리보기를 만듭니다. 따라서 이미지 다운로드·브라우저 캐시·디코딩 메모리 사용이 0이거나 반드시 작다고 보장하지 않습니다. 이미 받은 파일은 브라우저 캐시에 남을 수 있습니다.

## 적용
앞선 썸네일 카드 업데이트가 적용된 프로젝트 기준입니다. 같은 경로의 파일을 덮어쓰고 서버·프런트엔드를 함께 빌드·배포합니다. SQL이나 환경변수 추가는 없습니다. 운영 배포는 하지 않았습니다.

## 검증
CRA 빌드 성공. 카드 UI에서 첫 묶음 5개, 다음 5개, 마지막 2개, 이전 이동, 현재 묶음 외의 카드 제거, 구절판 미리보기 수, 아랍어 버튼 방향과 템플릿 제목 링크를 확인했습니다. 한국어/영어 구절판·티어표의 실제 빌드 JS를 JSDOM에서 실행해 5 → 5 → 2 표시와 마지막 버튼 비활성화를 확인했습니다. 실제 브라우저의 픽셀 배치나 네트워크 사용량 측정은 포함하지 않습니다.
