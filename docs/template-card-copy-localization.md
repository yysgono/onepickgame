# 원본 카드 중복 문구 삭제 / 구절판 작품 제목 언어 수정

- 원본 월드컵 카드 내부의 '이 후보로 이상형 월드컵 하기' 문구를 제거했습니다. 카드 위의 섹션 제목은 유지하고, 카드에는 원본 월드컵 제목만 표시합니다. 서버 HTML과 React 화면에 모두 적용합니다.
- 관련 구절판 작품 조회에 `source_worldcup_ids`를 포함하고, 연결된 템플릿의 등록된 언어별 제목을 이용해 작품 제목을 표시합니다. 같은 카테고리에서 가져온 다른 템플릿의 작품도 필요한 제목 메타데이터를 일괄 조회합니다.
- 예전에 '구절판'으로 저장된 작품과 현재 템플릿의 '구절판 취향표' 이름도 같은 기본 제목으로 인식합니다. ` - admin` 같은 작성자 부분은 유지합니다.
- 사용자가 직접 지은 제목은 임의로 템플릿 제목으로 덮어쓰거나 자동 번역하지 않습니다. 번역이 등록되지 않은 경우에는 기존 영어/원문 대체 규칙을 사용합니다.
- 제목 판별 로직을 서버와 브라우저가 같은 공통 모듈로 사용합니다. 저장된 제목이나 작성자 데이터, 등록/수정 권한은 변경하지 않습니다.
- 5개씩 넘기는 카드 동작과 섬네일 로딩은 유지합니다. 추가 이미지 풀이나 비공개 편집 정보는 조회하지 않습니다.

앞선 카드 업데이트가 적용된 프로젝트에 같은 경로로 덮어쓰고 서버·프런트엔드를 함께 빌드·배포하세요. 새 `localizedBoardTitleCore.js`도 반드시 포함해야 합니다. SQL이나 환경변수 추가는 없습니다. 운영 배포는 수행하지 않았습니다.

검증: CRA 빌드, 한국어/영어 구절판·티어표의 실제 빌드 실행, 카드 넘김 UI, 등록된 20개 언어 제목 선택, 이전 한글 명칭 호환, 다른 템플릿 작품의 번역, 작성자/직접 작성한 제목/저장된 값 유지 및 중복 문구 제거 검사 통과. 운영 DB 조회 및 실제 브라우저 픽셀 검증은 포함하지 않습니다.
