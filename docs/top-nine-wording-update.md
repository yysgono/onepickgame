# 최애 구절판 취향표 문구 정리

한국어 기본 명칭을 ‘최애 구절판 취향표’로 변경했습니다. 메뉴와 대표 제목에 전체 명칭을 사용하고, 반복되는 버튼·안내에는 ‘구절판 취향표’를 사용합니다.

적용: 메뉴, 구절판 홈, 만들기, 공개 목록, 불러오기/등록 안내, 관리자 화면, 사이트 소개, 검색용 제목·설명, 정책 안내의 기능 명칭. 한국어 템플릿 제목은 기존 저장값에 ‘취향표’가 없어도 표시할 때 보완하며, 중복해서 붙이지 않습니다. 템플릿 기반 제목의 언어 전환도 유지됩니다.

다른 19개 언어의 번역과 사용자가 직접 쓴 게시물 제목, URL은 변경하지 않습니다. DB에 저장된 별도 블로그 글이나 자유롭게 작성한 콘텐츠를 일괄 수정한 것은 아닙니다.

압축 파일을 같은 경로에 덮어쓴 뒤 배포하세요. SQL은 필요 없습니다. 이전 등록·로그인 복원 패치를 적용한 프로젝트 기준입니다.

검증: 한국어 외 번역 유지 확인, 템플릿 기반 제목의 언어 전환과 사용자 제목 유지 확인, 템플릿 및 홈 서버 HTML 검증 통과, 프로덕션 빌드 성공. 실제 배포는 수행하지 않았습니다.
