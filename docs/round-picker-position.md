# 월드컵 선택 페이지 제목·공유 버튼 배치

최종 순서는 제목 → 대표 사진 → 시작 라운드 선택 박스 → 소개 문구이다.

- 제목을 대표 사진 위로 이동했다.
- 이 선택 페이지에서 X·Threads·Instagram·링크 복사 버튼 묶음을 제거했다. 다른 페이지의 플랫폼 공유 버튼은 유지한다.
- 기존 상단 월드컵 공유/수정/삭제/결과 보기 버튼과 기존 공유 링크 동작은 유지한다.
- 선명한 라운드 박스 테두리와 선택지/시작/되돌리기 기능은 유지한다.
- 공통 페이지 수정으로 지원 언어 전체에 적용된다.

반영 소스는 src/components/SelectRoundPage.js이다. 추가 SQL·설정은 필요하지 않다.

최적화 프런트엔드 빌드와 한국어·영어 실제 번들에서 제목/이미지/라운드 순서, 플랫폼 버튼 제거, 게임 시작·진행·되돌리기를 확인했다. 로컬 수정이며 운영 서버 커밋·푸시·배포는 하지 않았다.
