# 월드컵 시작 라운드 박스 위치 수정

시작 라운드 선택 카드·시작 버튼·부활전 안내를 하나의 박스 그대로 소개 문구 바로 아래로 이동했다. 페이지에 한 번만 표시한다. 소개 문구가 없는 경우에는 제목 아래에 표시한다.

선택 페이지의 이미지와 제목 사이에 있던 One Pick Game 브랜드 문구를 제거했다. 다른 페이지의 브랜드 표시는 변경하지 않았다. 시작 라운드 박스 외곽선은 2px 보라색으로 선명하게 했다.

기존 라운드 선택 상태/추천, 시작 동작, 8명 미만일 때의 선택지, 진행도·되돌리기 동작은 유지했다. 기존 공유 버튼은 상단 위치에 유지한다. 지원 언어 전체에 적용된다.

반영 소스:
- src/components/SelectRoundPage.js
- src/components/worldcup/worldcupFlow.css

검증: 최적화 프런트엔드 빌드, 실제 한국어·영어 프로덕션 번들에서 단일 라운드 박스/제목 아래 배치/선택 페이지 브랜드 제거, 시작 후 0/7→1/7·되돌리기, 후보 5명일 때 한 개 선택지와 0/4→1/4 동작.

추가 SQL이나 설정은 없으며, 로컬 수정까지 완료했다. 운영 서버 커밋·푸시·배포는 하지 않았다.
