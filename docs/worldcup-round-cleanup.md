# 월드컵 선택 화면 정리

- 상단 라운드 선택은 유지하고, 설명 아래의 중복 라운드 선택 영역을 삭제했습니다.
- 후보가 8명 이상이면 8강부터 시작합니다. 2강·4강 버튼은 표시하지 않습니다.
- 후보가 2~7명이면 그 후보 수를 사용하는 버튼 하나만 표시합니다. 0~1명은 대결을 시작할 수 없어 시작 버튼을 비활성화합니다.
- 예: 후보 259명 → 8,16,32,64,128,256,259강. 후보 5명 → 5강 하나.
- 라운드 카드와 시작 버튼의 글자를 가운데로 정렬했습니다. 버튼 묶음도 가운데로 모으고, 마지막 줄이 덜 찬 경우도 가운데에 놓습니다.
- ‘이 주제로 더 즐기기’ 박스를 월드컵 선택 화면과 그 화면의 서버 HTML에서 제거했습니다. 다른 콘텐츠 화면의 관련 링크 설정을 일괄 삭제한 것은 아닙니다.
- 기존 진행도와 새 게임 초기화는 유지됩니다. 언어와 관계없이 같은 규칙을 적용합니다.

같은 경로에 덮어쓴 뒤 배포하세요. 이전 월드컵 진행도 패치도 포함합니다. 새 utils/worldcupRounds.js를 반드시 포함해야 합니다. 서버 HTML 변경을 위해 server.js도 포함합니다. SQL은 필요 없고 실제 배포는 수행하지 않았습니다.

검증: 프로덕션 빌드 성공. 소수 후보·일반 후보·상한의 라운드 목록 검증, 기존 진행도·20개 언어 선택 컴포넌트 검증 통과. 실제 빌드 앱을 JSDOM으로 실행하여 상단 선택 영역 한 개, 관련 링크 박스 없음, 일반 게임의 8강 선택·0/7→1/7 및 되돌리기, 후보 5명에서 선택 버튼 하나·0/4→1/4를 확인했습니다. 실제 브라우저의 시각 검수와 운영 DB 변경은 수행하지 않았습니다.
