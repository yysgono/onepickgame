# 구절판 등록 확인 창 간소화

회원은 등록하기 클릭 시 계정과 닉네임을 확인한 뒤 기존 이미지 준비 및 공개 등록 처리를 바로 실행합니다. 별도의 공개 목록에 게시 확인 창은 열지 않습니다. 기존 작품 수정에서도 소유자 검증 후 바로 저장합니다. 인증된 비회원 수정 세션이 있으면 기존처럼 바로 저장합니다.

비회원은 수정·삭제에 필요한 닉네임/비밀번호/비밀번호 확인만 입력합니다. 공개 목록 안내문과 사진 9장 안내문은 제거했습니다. 첫 등록 비회원에게 비밀번호 없이 공개 작품을 만드는 변경은 아닙니다. 비회원 등록 입력 창 제목과 제출 버튼은 호출한 등록하기 문구를 사용합니다. 공통 렌더링 변경이므로 모든 언어에 적용됩니다.

기존 비밀번호 증명, 업로드 용량/수량 제한, 중복 제목 재시도 및 등록 후 작품 페이지 이동을 유지합니다. 새 SQL·환경 변수는 없습니다. 저장소 커밋·푸시 및 실서비스 배포는 수행하지 않았습니다.

## 검증

프로덕션 빌드, git diff --check 통과. React UI에서 회원 확인창 없이 등록, 중복 제목 재시도, 실패 후 재시도, 다른 소유자의 작품 수정 차단, 비회원 자격 입력만 남은 창, 증명값을 통한 등록을 검증했습니다. 실제 빌드 번들의 비회원 티어표/구절판 정지 사진 업로드·실패 후 재시도·정상 인증 세션 유지 검사도 통과했습니다. 실제 브라우저 시각 검증은 별도로 수행하지 않았습니다.
