# 월드컵 홈 창 크기 변경 수정

월드컵 홈 상단은 600px 이상의 모든 화면에서 최소 280px + 660px + 280px에 간격·여백을 더한 3열을 유지했습니다. 좁은 창에서는 상단 내용이 넘칠 수 있고, 홈의 카드 트랙이 상위 요소의 최소 콘텐츠 너비에 영향을 줄 여지도 있었습니다.

## 변경

- 홈에 inline-size containment 및 min-width:0을 적용해 카드 트랙의 고유 너비가 페이지 너비를 강제하지 않게 했습니다.
- 상단 3열은 축소 가능한 열로 구성하고, 1440px 미만에서는 제목·검색을 위에, 최근 생성·플레이 목록을 아래 2열에 배치합니다. 800px 미만에서는 아래 목록을 1열로 전환합니다. 기존 600px 미만 모바일 목록 숨김은 유지합니다.
- resize 이벤트는 requestAnimationFrame으로 프레임당 한 번만 처리하고 해제 시 예약 프레임을 취소합니다.
- 모바일 카드 너비도 동일한 반응형 상태에서 계산합니다.
- 기존 페이지 데이터, 검색·정렬, 불러온 목록, 저장된 공통 썸네일 조회 방식은 유지합니다.

## 적용

이전까지의 수정이 적용된 프로젝트에 src/components/Home.js와 src/styles/homeResponsive.css를 같은 경로에 덮어쓰고 프런트엔드를 빌드·배포하세요. 새 SQL 또는 환경 변수는 필요 없습니다. 실서비스 배포는 수행하지 않았습니다.

## 검증

프로덕션 빌드 및 git diff --check 통과. 실제 빌드 번들을 JSDOM에서 실행해 1900→1100→500→1900px 연속 resize에 따른 모바일 전환, 카드 유지, 공통 썸네일 재조회 없음, 홈 최초 조회 재시작 없음, JavaScript 오류 없음을 확인했습니다. 출력 CSS의 반응형 규칙도 확인했습니다.

JSDOM은 실제 CSS 레이아웃을 계산하지 않으므로 시각적 잘림이 사라졌다는 브라우저 검증은 별도로 필요합니다. 이 환경의 로컬 Chromium 실행이 제한되어 실제 화면 크기 조절 검증은 수행하지 못했습니다. 배포 후 Chrome에서 창을 늘이고 줄이며 제목·최근 목록·카드의 잘림 및 클릭·스크롤 응답을 확인하세요.
