# 월드컵 라운드 버튼 · 진행도

## 라운드 선택
기존 드롭다운을 여러 라운드 선택 카드로 바꿨습니다. 해당 월드컵에서 지원하는 라운드를 모두 표시합니다. 선택한 카드는 색과 테두리로 구분하고, 라운드별 기본 선택 횟수를 함께 표시합니다. 기존 기본 최대 라운드를 추천으로 표시합니다. 시작 버튼에도 선택한 라운드를 넣었습니다. 기존 상단·하단 선택 영역이 같은 상태를 사용합니다.

키보드 Tab 및 방향키/Home/End로 라운드를 선택할 수 있습니다. 모바일은 두 열로 표시합니다.

## 새 게임과 이어하기
별도 이어하기 버튼은 추가하지 않았습니다. 현재 저장 상태는 기존 언어 전환 복원용 구조이며, 이를 일반 이어하기로 확대하지 않았습니다.

‘시작하기’에서는 해당 월드컵·라운드의 이전 세션 상태와 언어 전환 복원 표시를 먼저 지웁니다. 이후 기존 새 게임 초기화, 이전 본인 결과 정리, 무작위 대진 생성 흐름으로 들어갑니다. 서버의 다른 사용자 기록을 지우는 기능을 추가하지 않았습니다. 진행 중 언어 변경을 위한 기존 복원 기능은 유지합니다.

## 게임 진행도
게임 제목 위에 현재 단계·대결 번호, 전체 선택 횟수와 진행 막대를 추가했습니다. 실제 선택 이력과 현재 대진에서 계산하며 별도 저장 상태를 만들지 않습니다.

- 부전승은 사람의 선택 횟수에서 제외합니다.
- 되돌리기를 하면 횟수와 막대도 되돌아갑니다.
- 부활로 후보가 늘어나면 필요한 선택 횟수를 다시 계산합니다. 따라서 부활전 시 진행률이 조정될 수 있습니다.
- 막대에는 스크린리더용 진행도 속성을 넣었습니다.
- 라운드 선택·게임 진행도 문구는 20개 언어에 적용했습니다.

## 적용
압축 파일 안 파일을 같은 경로에 덮어쓴 뒤 배포하세요. 새 worldcup 폴더와 utils/worldcupProgress.js도 함께 포함해야 합니다. SQL은 필요 없습니다. 실제 배포, GitHub 커밋·푸시는 수행하지 않았습니다.

이번 패치는 라운드 선택과 진행도 표시입니다. 이미지 압축·썸네일·미리 불러오기 동작을 수정한 패치는 아닙니다.

## 검증
프로덕션 빌드 성공. 2~65명 대진을 각 라운드 끝까지 계산하여 기본 선택 횟수가 후보 수-1로 유지됨을 검증했습니다. 홀수 후보 부전승, 현재 라운드 밖 자동 진출 후보, 이력 되돌리기·추가 후보 계산, 20개 언어의 선택·시작·키보드 조작과 접근성 속성을 확인했습니다.

실제 빌드 앱을 JSDOM으로 한국어·영어에서 실행했습니다. 라운드 카드 선택, 정상 형태의 예전 저장 기록·언어 전환 표시가 남아 있어도 새 시작이 0/3에서 시작하는지, 선택 후 1/3, 되돌리기 후 0/3으로 바뀌는지, 기존 새 게임 기록 정리 호출이 유지되는지 확인했습니다. 실제 운영 DB를 변경하거나 실제 브라우저에서 시각 검수를 수행하지 않았습니다.
