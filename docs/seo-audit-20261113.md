# OnePickGame 검색 노출 점검 및 수정

## 결론
네이버 화면의 “미색인 문서로 검색대상이 아닙니다”는 현재 검색 색인에 들어 있지 않다는 뜻입니다. 정상적으로 색인되었다는 뜻은 아닙니다. 다만 그 문구만으로 제외 원인을 알 수는 없습니다. 오래 기다렸다는 이유만으로 앞으로 자동 해결된다고 보장할 수도 없습니다.

대상: https://www.onepickgame.com/ko/mytop9/templates/b1168231-f7da-4be1-afb9-17db9dfb2fa1

실제 배포 페이지와 프로젝트의 검색 관련 코드(서버 라우트, Vercel 연결, robots, 사이트맵 생성, 공통 SEO, 페이지별 색인 설정)를 조사했습니다. 모든 게시물 또는 모든 코드 행을 실행 검증한 것은 아닙니다. 실제 HTTP 응답 42개를 검사했으며, 그중 20개는 동일 템플릿의 언어별 URL입니다.

## 실제 배포에서 확인한 사항

| 항목 | 결과 |
|---|---|
| 해당 템플릿의 20개 언어 URL | 모두 HTTP 200, index,follow |
| 대표 URL(canonical) | 각 언어의 자기 주소로 지정됨 |
| robots.txt | Yeti의 해당 페이지 접근 허용 |
| 한국어·영어 사이트맵 | 해당 언어의 템플릿 URL 포함 |
| 존재하지 않는 템플릿 UUID | HTTP 404 |
| 첫 HTML | 제목, 소개, 후보 이름 4개 포함. 후보 이미지 없음. Loading 문구도 함께 남음 |
| 공개 구절판 상세, 퀴즈, 티어표, 블로그 표본 | 첫 HTML에 실제 제목과 내용 있음 |
| 구절판 홈 한국어·영어 | 첫 HTML에 템플릿/공개 게시물 링크 있음 |

따라서 해당 템플릿의 현재 미색인을 robots 차단, 현재 noindex, 사이트맵 누락으로 설명할 증거는 없습니다. 네이버가 과거 어떤 응답을 평가했는지, 내부적으로 중복/품질/렌더링 문제 중 무엇을 판단했는지는 서버 응답만으로 확인할 수 없습니다.

## 발견하여 수정한 코드

1. 구절판 템플릿은 서버에서 데이터를 이미 읽었는데도 브라우저가 다시 조회했습니다. 그 사이 첫 HTML의 내용을 로딩 화면으로 교체했습니다. 이제 서버가 받은 공개 후보 데이터를 안전하게 전달하여 첫 화면에서 바로 사용합니다. 직접 접속에서는 같은 템플릿을 다시 조회하지 않습니다. 앱 내부 이동이나 초기 데이터가 없는 경우에는 기존 조회와 재시도를 유지합니다.
2. 템플릿 첫 HTML에 후보 12개의 실제 이름과 이미지를 넣고, 중복 Loading 문구를 제거했습니다. 짧은 소개 문구는 유지합니다. 구절판 템플릿의 모든 지원 언어에 적용됩니다. 같은 렌더러를 쓰는 티어 프리셋에도 첫 HTML의 후보 표시 개선이 적용됩니다.
3. 랜덤 추천 주제 페이지(anime, movies 등 10개)는 서버에서 색인을 허용하지만 공통 클라이언트 허용 목록에서 빠져 있었습니다. 추천 주제 설정에서 허용 목록을 생성하도록 일치시켰습니다. 이는 별도 페이지에서 발견한 문제이며, 해당 구절판 템플릿의 미색인 원인이라는 뜻은 아닙니다.

이 변경은 확인된 렌더링 취약점과 설정 불일치를 개선합니다. 네이버의 실제 제외 사유가 이것이었다고 확정하거나 색인을 보장하는 수정은 아닙니다.

## 유지한 색인 제외
로그인/관리자/내 콘텐츠, 실제 편집·복제 화면, 미공개 공유 링크, 존재하지 않는 자료 등에는 목적에 맞는 noindex를 유지했습니다. worldcup-maker는 작성 폼으로 서버가 noindex를 지정하고 있습니다. 티어 프리셋이 아닌 월드컵 ID를 tier-list/create에 넣은 주소도 noindex가 의도된 동작입니다. 이 설정을 공개 구절판 템플릿의 차단으로 혼동하면 안 됩니다.

공개 구절판 상세 등 다른 일부 화면에는 여전히 클라이언트 조회 중 로딩 UI가 있습니다. 해당 표본의 첫 HTML에는 게시물 내용이 존재하며, 이번 패치는 구절판 템플릿의 중복 조회를 제거합니다. 모든 페이지의 로딩 UI를 제거한 패치는 아닙니다.

## 검증
- 프로덕션 빌드 성공.
- 20개 언어의 템플릿 HTML, 자기 대표 URL, 후보 12개, JSON 삽입 안전성 검증 통과.
- 실제 빌드된 JavaScript를 JSDOM에서 실행: 한국어·영어 템플릿에 후보 12개 표시, 템플릿 재조회 없이 진입, noindex 없음, 대표 URL 일치.
- 잘못된/누락된 초기 데이터는 기존 조회로 돌아가도록 검증.
- 서버 200/404/503, 구절판 홈 내부 링크, 티어 만들기/월드컵 결과·통계의 20개 언어 HTML 회귀 검증 통과.
- 공개 페이지 허용 목록과 비공개 페이지 제외 설정 검증 통과.
- 실제 Chrome/네이버 렌더링 엔진에서 실행한 검증은 아니며, 네이버 색인 결과를 재현한 테스트도 아닙니다.

## 적용
압축 파일의 파일을 같은 경로에 덮어쓴 뒤 정상 배포 여부를 확인하세요. 새로운 파일 src/components/topNine/templateBootstrap.js도 반드시 포함해야 합니다. SQL 실행은 필요 없습니다. 빌드 결과물 자체는 압축에 포함하지 않았습니다.

실제 서비스에는 아직 적용하지 않았습니다. 배포 후 네이버에서 URL 검사와 수집 요청을 한 번 진행하고, 최종 업데이트가 배포 이후로 갱신되었는지 확인하세요. 계속 미색인이라면 로딩 문제만으로 단정하지 말고 페이지별 고유 내용, 중복 템플릿, 내부 링크와 네이버 진단 결과를 함께 조사해야 합니다.

네이버 공식 설명: https://searchadvisor.naver.com/guide/seo-advanced-indexing
수집된 문서가 모두 색인되는 것은 아니며, 렌더링 결과가 비어 있거나 오류인 경우 색인에 문제가 생길 수 있다는 안내입니다. 특정 사이트의 제외 사유를 알려 주는 문서는 아닙니다.
