# 한국 쿠팡 / 해외 아마존 상단 배너

사용자가 Amazon Link Checker에서 검증한 주소:
https://www.amazon.com/?tag=onepickgamegl-20

## 동작
월드컵·티어표·퀴즈·뽑기·구절판의 보조 메뉴 바로 아래에 한 개만 표시합니다. 국가 판정은 기존 Vercel 방문 국가 헤더를 사용합니다.

- 한국(KR): 기존 쿠팡 배너(ID 920431, AF6207831). PC 728×90, 모바일 320×100.
- 해외: 새 ID onepickgamegl-20을 사용하는 Amazon.com 제휴 링크 배너. PC 728×90, 모바일 최대 320×100. 제목과 버튼 등은 20개 페이지 언어에 맞춥니다.
- 국가 확인 불가: 광고를 선택하지 않고 예약된 공간만 유지합니다.
- 관리자·개인 콘텐츠 등 기존 제외 화면에는 표시하지 않습니다.

아마존 배너는 사이트에서 디자인한 일반 텍스트 배너입니다. 상품 이미지·가격·재고를 표시하거나 상품을 자동 추천하지 않습니다. 계정에서 받은 공식 이미지 배너라고 표현하지 않습니다. 이미지 API나 별도 API 키도 사용하지 않습니다.

검증된 새 태그만 사용하고 종료된 onepickgame-20은 사용하지 않습니다. 링크 클릭 전에는 Amazon으로 자동 이동하거나 Amazon 요청을 보내지 않습니다. 제휴 링크에는 sponsored/nofollow와 새 창 보호 속성을 넣었습니다. 방문자 식별 정보를 제휴 URL에 붙이지 않습니다.

## 제휴 고지와 연결 국가
배너 근처에 각 언어의 제휴·수수료 안내를 넣고, 공식 영문 고지 “As an Amazon Associate I earn from qualifying purchases.”도 표시합니다.

현재는 모든 해외 접속을 미국 Amazon.com으로 연결합니다. 국가별 Amazon.co.jp, Amazon.co.uk 등으로 자동 연결하거나 각 국가에서 수익을 받도록 하는 OneLink 설정은 이번 작업에 포함하지 않았습니다. 이번 링크 유효성 확인은 계정 최종 승인이나 실제 구매 수익 보장을 의미하지 않습니다.

## 적용
이 압축은 이전 쿠팡 배너 파일까지 포함합니다. 모든 파일을 같은 경로에 덮어쓰고 배포하면 됩니다. server.js, vercel.json, affiliate-country.cjs도 포함해야 국가 조회 API가 동작합니다. SQL은 필요 없습니다. 기존 Google 자동광고 설정은 변경하지 않았습니다.

광고 로딩 전부터 영역 높이를 확보하고 모바일에서는 보조 설명을 생략하여 공간을 줄였습니다. 실제 접속 국가 판정과 아마존 수익 집계는 배포 후 확인하세요. 쿠팡·아마존 실적을 만들기 위한 자동 클릭이나 구매는 수행하지 않았습니다.
