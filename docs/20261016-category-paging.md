# 모든 월드컵 카테고리 페이지의 초기 조회 줄이기

프로젝트를 백업한 뒤 이 ZIP의 src, scripts, docs 폴더를 프로젝트 최상위에 덮어쓰고 커밋·푸시해서 배포하세요. 새 파일도 함께 복사해야 합니다.

이미 적용한 get_worldcup_home_rows 조회 함수를 재사용합니다. 추가 SQL이나 DB 변경은 없습니다. 기존 홈 로딩 개선 파일의 worldcupHomePager.js 및 worldcupHomeApi.js가 프로젝트에 있어야 합니다.

적용 대상은 16개 언어의 인물, 음악, K-Celeb, 게임, 스포츠, 애니/만화, 영화/드라마, 음식, 기타 월드컵 카테고리입니다.

- 처음에는 선택한 카테고리의 12개만 받습니다. 전체 월드컵 조회를 기다리지 않습니다.
- 더보기는 같은 카테고리의 다음 12개를 추가 조회합니다.
- 기타도 처음 12개, 다음 12개 기준입니다.
- 검색은 DB 전체 카테고리 데이터의 제목·설명·번역·후보 등을 기준으로 처리합니다.
- 인기순·최신순은 DB에서 정렬한 뒤 해당 페이지를 반환합니다. 최신순은 기존 조회 함수의 recent 값으로 전달합니다.
- 카드의 우승 통계는 반환된 카드만 조회합니다. 더보기 때 기존 카드의 통계 요청을 반복하지 않습니다.
- 카드에 표시하는 참여 횟수는 목록의 play_count를 사용해 통계 응답 순서 때문에 인기순이 바뀌지 않게 했습니다.
- 페이지를 추가로 받다가 실패하면 기존 카드는 유지하고 재시도할 수 있습니다.
- 기존 서버 SEO HTML·사이트맵·게임 진행·결과·로그인 코드는 변경하지 않았습니다.

검증: 실제 CategoryPage React 마운트, 9개 카테고리 전환, 첫 조회·다음 페이지·중복 클릭·미표시 카드 통계 제외·숨겨진 게임 검색·최신순·실패 및 재시도, 기존 홈 페이징 회귀 검사, React production build. 운영 DB에는 읽기 요청으로 기존 함수의 카테고리·범위·정렬 지원만 확인했습니다.
