# 티어표·구절판 프리셋 내부 링크 (2026-11-17)

## 적용 내용
- 티어표 홈의 첫 HTML에 추천 프리셋 제목과 `/언어/tier-list/create/원본ID` 링크를 최대 48개 제공합니다. 후보 사진 풀을 추가로 내려받지 않고 공개 제목 메타데이터를 사용합니다.
- 티어표와 구절판의 개별 프리셋에 다음 링크를 제공합니다.
  - 원본 후보의 이상형 월드컵 시작 페이지
  - 같은 프리셋/원본을 사용한 공개 작품 최대 12개(조회수순)
  - 다른 추천 템플릿 최대 12개(조회한 추천 목록에서 같은 카테고리 우선)
- 구절판과 티어표 모두 첫 HTML과 실제 React 화면에 표시합니다. 서버가 조회한 링크 메타데이터를 초기 화면에서 재사용합니다. 실제 화면에서는 제작 영역 아래에 표시합니다.
- 기존 대시보드의 원본 연결을 이용합니다. 다시 등록하거나 후보 이미지를 다시 업로드하지 않습니다. 같은 템플릿으로 만든 공개 작품이 없으면 해당 작품 섹션은 표시하지 않습니다.
- 문구는 20개 언어에 반영했습니다. 제목·소개문·대표 주소·기존 색인 설정은 유지합니다.

## 운영 조건
- 기존 공개 원본/추천 목록/작품 조회 권한을 그대로 사용합니다. 로그인 토큰이나 관리자 키를 새로 사용하지 않습니다.
- 수정·복제 및 개인 목록에는 공개 추천 조회를 추가하지 않습니다.
- 추가 조회는 기존 공개 테이블/RPC의 제목·ID·분류 등 메타데이터만 사용합니다. 기존 원본 후보 로딩은 유지합니다.
- 추가 조회에는 약 3.5초 제한을 두며, 실패하더라도 기존 제작 페이지를 실패 처리하지 않습니다. 홈의 프리셋 조회 실패 응답은 캐시하지 않습니다.
- 원본 월드컵/프리셋 공개 여부는 기존 설정을 따릅니다. 미등록 프리셋을 자동으로 공개하거나 사이트맵에 강제로 추가하지 않습니다.

## 적용 방법
이전 업데이트가 적용된 프로젝트에 ZIP 파일을 같은 경로로 덮어쓰고 서버·프런트엔드를 함께 빌드하여 배포합니다. 추가 SQL·환경변수·대시보드 재등록은 필요 없습니다. 작업 중 운영 배포나 운영 DB 변경은 수행하지 않았습니다.

배포 후 티어표 홈과 개별 프리셋의 페이지 소스에서 `template-discovery`, `select-round/원본ID`, 프리셋 URL을 확인하세요. 기존 수집 문서는 검색엔진이 재수집해야 갱신되며, 이 개선만으로 검색 순위나 색인을 보장하지 않습니다.

## 검증
- CRA 배포 빌드 통과.
- `node tests/template-discovery.cjs`: 서버 렌더링, 원본·같은 템플릿 작품·관련 프리셋 관계, 20개 언어, HTML/JSON 안전한 출력, 잘못된 ID 제외, 수정/개인 목록 제외, 홈 메타데이터 조회 실패 처리.
- `node tests/template-discovery-production.cjs <빌드경로>`: 실제 빌드 JS를 JSDOM에서 구절판·티어표 각각 한국어/영어로 실행. 첫 HTML의 링크가 React 실행 후에도 유지되고, 서버 링크 데이터 재사용·제작 화면·최종 색인 허용 상태를 확인했습니다.
- 기존 구절판 서버 후보 재사용과 티어표 추천 후보 선택/가져오기 검증도 실행했습니다.
- 실제 운영 검색엔진 색인 및 검색 순위 검증은 포함하지 않습니다.

후속 디자인: 텍스트 목록을 썸네일 카드와 좌우 넘김 목록으로 변경했습니다. `docs/template-discovery-cards.md`를 참고하세요.
