# 종합 홈 문구·카드 디자인·넓은 화면 수정

이 묶음은 종합 홈, 월드컵 목록 주소 분리, 홈 API 누락 시 공개 조회 보완을 포함합니다. 이전 홈 수정 ZIP 대신 같은 경로에 적용하세요.

## 화면과 문구

- 게임 순서는 헤더와 동일한 **월드컵 → 퀴즈 → 티어표 → 구절판 → 랜덤 뽑기**입니다.
- ‘내 취향을 고르고, 만들고, 공유하세요’와 각 언어의 같은 상단 제목을 표시하지 않습니다. 종합 홈의 중앙 로고에 있는 사이트 이름을 단일 H1로 사용합니다.
- 게임 선택 버튼에는 짧은 한 문장, 각 게임 섹션 제목 아래에는 적당한 길이의 두 문장 소개를 표시합니다. 20개 언어에 서로 구분된 문구를 제공합니다.
- 선택 버튼의 테두리는 게임별 색상으로 진하게 표시합니다. 아이콘과 게임 이름도 키웠습니다.
- 게임 섹션 제목·소개문·카드 제목과 후보 소개는 가운데 정렬합니다. 제목 옆에 ‘전체보기’ 버튼을 붙이고 제목·소개문 글씨를 키웠습니다. 두 링크는 같은 기존 목록으로 연결됩니다.
- 게임 선택 박스 바로 아래에 기존 목록과 같은 20개 언어 선택을 표시합니다. 헤더와 같은 페이지 언어를 사용하며 변경하면 제목·설명·카드와 링크의 언어를 함께 바꿉니다.
- 종합 홈에서만 헤더의 중복 게임 메뉴를 제외하고 로고를 가운데 배치합니다. 언어 선택·계정·커뮤니티 메뉴와 다른 페이지의 기존 게임 헤더는 유지합니다.
- 본문은 최대 1800px로 가운데 배치하고 넓은 화면에서는 양옆 여백을 둡니다. 기존 카드 크기를 유지하며 가로 스크롤바는 숨깁니다. 화살표 버튼·터치 이동과 스크롤 스냅을 사용합니다.

## 기존 게임 카드 재사용

월드컵 카드는 기존 목록과 같은 후보 소개 생성 함수를 공유합니다. 두 후보 이름만 표시하던 소개를 기존 후보 이름 목록으로 되돌렸고, 후보 수·플레이 수·날짜·통계/댓글·시작 버튼을 표시합니다. 제목 배경과 카테고리별 하단 색상도 기존 디자인에 맞췄습니다. 데스크톱 카드 폭은 504px, 최소 높이는 452px이며 모바일에서는 화면에 맞춥니다.

퀴즈는 기존 카테고리 목록과 종합 홈에서 `QuizCard` 컴포넌트를 공유합니다. 같은 사진 비율, 문제 수·플레이 수, 카드 아래의 빨간 ‘지금 풀기’ 버튼을 사용합니다. 데스크톱 폭은 기존 카테고리 카드와 같은 440px입니다. 문제·플레이·시작 문구는 20개 언어로 표시합니다.

티어표는 기존 목록과 `TierCardPreview`를 공유합니다. 420px 폭의 대표 이미지와 등급 미리보기를 표시하며 **홈에서는 조회수 등 카운터를 표시하지 않습니다**. 미리보기는 네 등급별 최대 다섯 명으로 제한합니다.

## 티어표 제목

홈에서 사용자가 보는 주제 이름은 연결된 원본 월드컵의 `tier_preset_title_translations`에 설정한 제목을 우선합니다. 이전 저장 결과나 번역 제목에 ‘순위’라는 SEO 문구가 남아 있어도 관리자가 설정한 프리셋 제목이 있으면 그 제목을 그대로 표시합니다. 설정 제목 자체에 포함한 단어는 삭제하지 않습니다. 저장 결과의 제목과 상세 페이지에 사용자가 직접 지정한 제목은 변경하지 않습니다.

최적화된 `tier_list_home_cards` 뷰를 그대로 사용합니다. 기존 원본 언어 정보는 기본 테이블에서 ID별로 묶어서 확인하므로 새 뷰 컬럼이 필요하지 않습니다. 뷰가 실패하면 공개 `tier_lists`를 사용하며 뷰에만 있는 계산 컬럼을 기본 테이블에 요구하지 않습니다.

## 넓은 화면과 이어 불러오기

이전 홈에는 섹션별 최대 8개 제한이 있었습니다. 이후 카드 조회 제한을 고쳤고, 최신 요청에 따라 본문에는 좌우 여백을 다시 적용했습니다.

- 처음에는 섹션별 5개와 다음 페이지 존재 여부를 확인할 한 개를 조회합니다.
- 카드가 화면 폭을 채우지 못하면 해당 게임의 다음 페이지를 자동으로 불러옵니다.
- 오른쪽 끝으로 스크롤하거나 다음 버튼을 누르면 이어서 조회합니다. 이미 표시한 카드는 유지합니다.
- 추가 요청은 해당 게임만 조회합니다. 언어·게임 종류·위치·개수별로 캐시를 구분하고, 서버 캐시는 최대 128개 항목으로 제한합니다.
- 같은 추가 요청은 합치고 카드 링크로 중복을 제거합니다. 언어 변경·페이지 이탈 시 늦은 응답을 무시하고 요청을 취소합니다.
- 추가 조회 실패 시 기존 카드를 유지하고 해당 섹션에서 다시 시도할 수 있습니다.

기존 인기 정렬은 유지합니다. 월드컵·퀴즈·랜덤 뽑기는 누적 플레이 수, 티어표·구절판은 조회수 기준으로 정렬합니다. 정렬 기준으로 조회수를 사용하는 것과 홈에 그 숫자를 표시하는 것은 별개입니다.

## 조회와 이미지

월드컵 썸네일은 기존 공용 저장소에 저장된 상위 두 후보 이미지를 재사용합니다. 새로운 우승 통계를 계산하거나 결과 순위를 다시 조회하지 않습니다. 기존 소개문과 후보 수를 표시하기 위해 현재 페이지에 포함된 월드컵의 공개 후보 메타데이터를 읽습니다. API에는 소개문·후보 수·썸네일 주소만 전달하며 전체 후보 배열은 포함하지 않습니다.

티어표·구절판은 등록된 이미지 경로와 제한된 배치 정보를 사용합니다. 브라우저 이미지는 지연 로딩합니다. 넓은 화면에서 카드를 더 표시하면 필요한 메타데이터와 이미지 요청도 늘어납니다. 모든 게임을 한 번에 전부 조회하지는 않습니다.

홈 API가 없는 개발 서버나 잘못된 API 응답은 기존 공개 연결을 통해 복구합니다. 초기 데이터가 정상이라면 브라우저는 해당 데이터를 재사용합니다. 새 데이터 버전은 이전 형식과 섞이지 않도록 갱신했습니다.

## 적용과 검증

1. ZIP의 수정 파일을 프로젝트 루트에 같은 경로로 덮어씁니다. 전체 프로젝트 ZIP이 아닙니다.
2. 로컬에서는 개발 서버를 다시 시작하고 새로고침합니다.
3. 운영에는 기존 `npm run build`를 실행하고 프런트엔드·서버·라우팅 설정을 함께 배포합니다. 기존 빌드 명령에 사이트맵 생성이 포함되어 있습니다.

새 SQL이나 환경변수는 없습니다. 기존 개별 URL, `/:lang/ideal-type-world-cup`, 원본 월드컵 ID, 후보 연결과 저장 결과는 유지합니다. 운영 배포는 수행하지 않았습니다.

검사는 테스트 데이터를 사용합니다. 20개 언어 초기 HTML·대표 주소·사이트맵·직접 접속·언어 변경·API 누락 복구, 기존 링크, 제목·등급 미리보기, 티어표·구절판 결과와 비회원 사진 등록을 확인했습니다.

35개씩 등록된 퀴즈·티어표·구절판 자료로 다음 버튼을 통한 추가 조회, 여백이 있는 넓은 화면에서 불필요한 추가 조회 방지, 반복 축소/확대 후 요청 종료와 중복 카드 방지를 확인합니다. 원본 소스에 수정 ZIP을 덮어쓴 별도 작업본의 빌드도 확인합니다.

프로덕션 번들 동작 검사는 JSDOM을 사용하며 넓은 화면 검사는 레이아웃 치수를 모의합니다. 실제 Chrome/Edge에서 수정본의 픽셀 단위 화면을 검수한 것은 아닙니다. 빌드 검사에서는 실서비스 사이트맵 DB 조회를 실행하지 않고 React 빌드 단계를 직접 실행했습니다.

## 소개문·말줄임·간격 보완

20개 언어의 섹션 소개문은 문장 단위로 줄을 나누며, 작은 화면에서는 자연스럽게 추가 줄바꿈합니다. 월드컵 카드의 긴 후보 소개는 내부 텍스트에 두 줄 말줄임을 적용해 세 번째 줄이 비치지 않게 했습니다. 언어 선택의 위 간격은 10px, 첫 게임 박스까지의 간격은 12px로 줄였습니다. 퀴즈 물음표는 가로 폭을 키워 더 두툼하게 표시합니다.

사이트맵 생성 코드는 20개 언어의 새 월드컵 홈을 포함하며 기존 개별 URL을 유지합니다. 홈 종류별 메타정보를 분리했고, 월드컵 전용 화면 소개는 기존 문구를 유지합니다. 실제 사이트맵 생성은 운영 빌드 시 실행합니다.

## 카드 테두리와 구절판 초기 이미지

티어표 카드는 기본 상태부터 파란 테두리를 표시합니다. 구절판 초기 서버 HTML의 사각 격자를 기존 구절판과 동일한 다각형 배치로 바꿨습니다. 서버와 편집기·공개 목록은 공용 배치 파일을 사용하며, 브라우저에서는 기존 BoardThumbnail의 저장된 사진 확대·위치를 적용합니다. 언어 선택 위 간격은 4px로 줄였습니다.

## 구절판 메뉴 아이콘·로고 글자

구절판 메뉴의 글자 격자 아이콘을 기존 헤더와 같은 아홉 칸·중앙 보라색 아이콘으로 교체했습니다. 홈 선택 버튼과 섹션 제목, 초기 HTML에 동일한 모양을 표시합니다. 헤더의 One Pick Game 글자 크기는 기존 대비 14% 키웠습니다.

## 월드컵 홈의 사이트 전체 소개 제거

월드컵 목록 홈에서 사이트 전체 게임을 안내하는 문단을 20개 언어 모두 제거했습니다. 브라우저와 초기 HTML에 동일하게 적용하며 월드컵 전용 소개·메타정보와 종합 홈 소개는 유지합니다.

## 처음 다섯 개씩 조회

종합 홈은 게임별로 처음 5개를 표시하고, 가로로 넘길 때 다음 5개씩 이어 불러옵니다. 기존 12개 데이터가 초기 화면에 재사용되지 않도록 홈 데이터 버전을 갱신했습니다. Vercel CSS 누락 오류 수정도 이 묶음에 포함합니다.

## 상단 게임 버튼 효과

상단 게임 선택 버튼 다섯 개는 마우스를 올리면 6px 위로 떠오르며 그림자가 진해집니다. 주변 배치는 움직이지 않으며 키보드 포커스에도 표시합니다. 터치 환경에서는 마우스 효과를 적용하지 않고, 동작 줄이기 설정에서는 이동 효과를 생략합니다.
