# 결과 추천·최근 플레이·안내 문구 수정 (2026-11-16)

## 화면 변경
- 가입 안내의 가입 방법 문장과 약관·개인정보처리방침 확인 문장을 줄바꿈합니다. 지원하는 언어에 함께 적용했습니다.
- 구절판 비회원 안내는 구절판 최대 9장·비밀번호 수정/삭제만 설명합니다. 티어표 언급과 압축·업로드 내부 설명을 제거했습니다. 티어표는 별도로 PC 사진 50장과 비밀번호를 안내합니다. 실제 압축·업로드 기능과 제한은 유지합니다.
- 티어표 원본 제목 입력칸 테두리를 `2px solid #7c6bb8`로 진하게 변경했습니다.
- 구절판 홈의 인기순 기준 설명문을 삭제했습니다. 정렬 기능은 유지합니다.

## 최근 플레이 목록
- 월드컵·퀴즈의 플레이 이벤트를 중복 제거 없이 최신순으로 최대 4줄 표시합니다. 같은 게임의 기록이 네 개면 네 줄 모두 같은 게임일 수 있습니다.
- 공개·미삭제 게임의 기록만 연결합니다. 기존 winner_logs / quiz_attempts 기록을 사용하며 플레이 집계 방식을 변경하지 않습니다.
- 24시간 미만은 언어별 상대 시간(예: 3분 전, 5시간 전), 24시간 이상은 날짜로 표시합니다.
- 월드컵 홈은 기존 페이지 나누기 RPC의 중복 제거 결과 대신, 최근 이벤트 60개와 해당 게임의 제목·분류 메타데이터를 별도로 읽습니다. 전체 후보 이미지 풀을 읽지 않습니다. 퀴즈도 동일한 공통 조회 함수를 사용합니다.

## 결과 페이지 추천 박스
- 월드컵: 현재 게임을 제외하고 같은 카테고리에서 최근 플레이된 게임을 우선 표시합니다. 부족하면 다른 최근 게임으로 채웁니다. 추천 카드 자체는 같은 게임을 중복 표시하지 않습니다. 섬네일은 선정된 최대 4개 게임에서 후보 1개씩만 가져옵니다.
- 티어표: 같은 원본 월드컵 또는 같은 프리셋 이름을 우선하고, 해당 그룹 안에서 조회수 내림차순·최신순으로 표시합니다. 부족하면 같은 카테고리, 전체 공개 티어표 순서로 채웁니다.
- 구절판: 공통 원본 템플릿이 있는 작품을 조회수순으로 우선하고, 같은 카테고리·전체 목록으로 채웁니다. 기존 DB의 배열/JSON 소스 필터 형식 차이에 대응합니다.
- 최대 4개. 현재 작품은 제외합니다. 권한 정책은 그대로 적용하며, 조회 실패 또는 추천할 작품이 없으면 박스를 숨깁니다. 비공개 구절판과 편집 화면에는 추천을 표시하지 않습니다.
- 추천 카드에서 각 작품의 상세/시작 페이지로 이동합니다. PC·모바일과 RTL을 지원하며 제목·조회 문구는 20개 언어로 제공합니다.

## 적용과 검증
이번 화면·조회 수정만을 위한 추가 SQL이나 환경변수는 없습니다. 앞선 비회원 사진 업로드를 함께 처음 적용하는 경우에는 `docs/guest-content-uploads.md`의 SQL·서버 설정이 여전히 필요합니다.

로컬 검증: CRA 빌드 성공. 실제 빌드 JS를 실행한 JSDOM에서 한국어·영어 각 홈/퀴즈 홈/가입/티어표 제작/구절판 결과/티어표 결과/월드컵 결과 14개 경로 확인. 별도 테스트에서 반복 이벤트, 상대 시간, 템플릿·카테고리 우선순위, 조회수 정렬, 자신/삭제된 항목 제외, 메타데이터만 조회하는 조건을 확인했습니다. 운영 DB에 쓰거나 운영 배포를 수행하지 않았습니다.

- `node tests/guest-content-upload-copy.cjs`
