# 구절판 사진 위 이름표 폭 확대

사진 위 이름표와 이름 편집 입력칸의 가로폭을 사진 영역 기준 70%에서 80%로 조금 넓혔다. 글자 크기와 한 줄 표시는 유지하며, 아주 긴 이름은 기존처럼 말줄임한다. 저장된 후보 이름은 변경하지 않는다.

다운로드 PNG에서도 이름을 담는 가로폭을 같은 방향으로 넓혔다. 구절판 사진 배치·크기·저장 구조는 변경하지 않았다. 언어에 공통으로 적용된다.

반영 파일:
- src/components/topNine/topNine.css
- src/components/topNine/media.js

최적화 CRA 빌드 및 git diff --check 확인. 새 SQL이나 설정은 필요 없다. 운영 서버 커밋·푸시·배포는 하지 않았다.
