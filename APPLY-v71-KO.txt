적용 순서
1. Supabase SQL Editor에서 supabase/20261026_community_blog.sql 내용을 실행하세요.
   이 SQL은 대화에서 확인한 기존 운영자 계정(yysgono@gmail.com)에 글 발행 권한을 줍니다.
   해당 이메일이 실제 운영자 계정과 다르면 실행 전에 수정하세요. 계정을 찾지 못하면 전체 작업이 취소됩니다.
2. ZIP의 src 폴더, server.js, vercel.json을 같은 경로로 덮어쓰세요.
3. npm run build 후 기존 방법으로 커밋·푸시·배포하세요.
4. 운영자 계정으로 로그인한 후 /ko/blog에서 글쓰기 버튼을 확인하세요.

변경 사항
- 상단 언어 선택/로그인 영역 최대 폭 270px. 아래 메뉴 글자 확대.
- 공지사항 / 자유게시판 / 건의사항 / 내 콘텐츠 / Blog 순서.
- 준비 중 표시 제거. 공지사항은 운영자, 자유게시판은 로그인 회원이 글 등록 가능.
- 게시판 글 열람·삭제·12개씩 더보기. 댓글, 게시판 이미지 첨부, 글 수정은 이번 기본 버전에 미포함.
- Blog 기존 글/주소 유지. 목록 처음 12개, 더보기로 추가 조회.
- 운영자용 글쓰기 및 기존 글 수정. 제목/소개/본문/언어(16개) 선택.
- 본문 굵게/기울임/소제목/링크/이미지 URL 삽입. 컴퓨터 이미지 파일 업로드 및 자동 번역은 미포함.
- 같은 slug의 다른 언어 글은 기존 글의 수정 화면에서 글 언어를 바꿔 작성할 수 있습니다.
  예: 한국어 글 수정 -> 영어 선택 -> 영어 제목과 본문 입력 -> 발행.
  언어 변경 전에 입력한 내용은 먼저 저장하세요. 새 글 화면에서는 언어 변경 시 입력 내용이 초기화됩니다.
- 새 글이 기존 주소와 같으면 덮어쓰지 않고 오류 안내. 기존 글의 수정 화면을 이용하세요.
- 신규 게시판·편집 페이지는 초기 버전에서 noindex입니다. 기존 공개 Blog의 색인 설정은 유지합니다.

검증
JSX/서버 JS/CSS 문법, 메뉴 순서·경로 및 페이지 단위 조회 확인.
PGlite 모의 DB에서 SQL 재실행, 운영자 Blog 발행/수정/번역, 일반 회원의 Blog/공지 작성 차단,
자유게시판 등록/본인 삭제 확인. 실제 운영 DB 스키마에서 실행한 결과는 아닙니다.
전체 프로젝트 빌드, 실제 브라우저 시각 검사, 운영 배포는 미실행입니다.
