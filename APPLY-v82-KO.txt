1. Supabase SQL Editor에서 supabase/20261027_community_language_scope.sql을 실행하세요.
2. ZIP의 파일을 같은 경로에 덮어쓰세요. community-seo-routes.cjs는 프로젝트 최상위입니다.
3. 다시 빌드·배포하세요.

글쓰기에서 작성 언어 아래에 '이 언어 페이지에서만 표시' 체크박스를 추가했습니다.
기본은 체크 해제: 모든 언어의 자유게시판에 표시합니다.
체크하면 선택한 작성 언어의 자유게시판에서만 표시합니다. 운영자가 공지로 고정한 글에도 적용됩니다.
기존 글은 자동으로 전체 언어 표시를 유지합니다. 기존 글의 언어 제한을 자동 변경하지 않습니다.
공지사항 게시판은 기존처럼 언어별 표시를 유지합니다.
서버 초기 HTML에도 동일한 필터와 언어별 캐시를 적용하고, 대표 주소를 각 언어 주소로 맞췄습니다.
건의사항·공지 고정 등 v81 기능은 유지됩니다.

SQL은 새 열과 인덱스를 추가하며 기존 게시글을 삭제하지 않습니다.
로컬 DB 및 서버 모의 테스트로 16개 언어 표시 범위, 기본값, 기존 글, 공지 고정 순서, 서버 필터/캐시/대표 주소를 확인했습니다.
운영 DB 실행과 실제 배포는 사용자가 진행해야 합니다.
