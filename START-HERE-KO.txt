기준 GitHub main d3feebb1d76427bdc7c360eaf48c2bec0c5d5c18

적용
ZIP의 수정 파일을 같은 경로에 덮어쓴 뒤 커밋·푸시·배포하세요.
SQL이나 새 패키지 설치는 필요 없습니다.
최상위 폴더를 통째로 새 프로젝트로 쓰는 것이 아니라 수정 파일만 덮어쓰는 패치입니다.

화면
- 순위표 이름 왼쪽에 PC 48px, 모바일 40px 이미지.
- 이름 칸은 전체 표의 34%, 이름은 2줄까지 표시. 마우스를 올리면 전체 이름 확인 가능.
- 통계 전용 화면의 상위 폭 제한 980px을 1200px로 확대.
- 표는 PC 최소 1040px, 모바일 최소 840px. 작은 창에서는 표 안에서 가로 스크롤.
- 기존 25개 기본/10·25·50·100개 선택, 정렬·검색·기간 필터·선택한 우승자 강조는 유지.

이미지
- 같은 탭에서 MediaRenderer가 성공적으로 불러온 이미지 주소를 메모리에 기록.
- 최근 원본이면 같은 주소로 재사용하여 브라우저 캐시 활용.
- 처음 불러오는 자기 Supabase 공개 저장소 사진이면 96×96, quality 70, contain 변환 URL 사용.
- 화면 주변 80px 이내로 들어오는 행부터 img를 생성하고 브라우저 lazy loading도 적용.
- 외부 사진·서명된 비공개 주소는 임의 변환하지 않고 기존 주소 유지.
- 동영상 파일은 통계표에서 재생/다운로드하지 않고 이름 첫 글자 표시. YouTube는 작은 정적 미리보기만 사용.
- 썸네일 변환 실패 시 원본으로 한 번 돌아가고 원본도 실패하면 글자 표시.
- 변환 오류 후 1분 동안 새 변환 시도를 줄입니다.

비용 확인
새 Supabase 썸네일은 Storage Image Transformations 사용량에 포함됩니다.
이미지 크기가 작아져도 변환 기능 자체가 무제한 무료인 것은 아닙니다.
세부 기준은 docs/IMAGE-USAGE-KO.md를 먼저 확인하세요.
변환 기능은 Supabase 설정을 대신 켜지 않습니다. 꺼져 있으면 원본 표시로 복귀합니다.
변환을 사용하지 않으려면 Vercel 환경변수 REACT_APP_STATS_IMAGE_TRANSFORMS=false로 설정한 뒤 재배포할 수 있습니다.
이 옵션을 끄면 이름 옆의 작은 화면 크기는 유지하지만 새 이미지도 원본 파일을 내려받을 수 있습니다.

캐시의 한계
성공적으로 불러온 주소가 곧 '현재 브라우저 캐시에 반드시 존재한다'는 보장은 아닙니다.
새로고침/다른 탭에서는 메모리 기록이 초기화되며, 만료/브라우저 캐시 제거 시 원본도 다시 요청될 수 있습니다.
기록은 최대 512개 주소, 1시간 참고용으로만 보관합니다. 실제 브라우저 캐시 TTL 보장이 아닙니다.
이미지 파일·Blob·개인별 플레이 기록을 localStorage나 DB에 추가 저장하지 않습니다.

검증
원본 URL 기록→통계표 재사용 통합 테스트, 지연 로드, 새 썸네일, 원본 복귀,
외부/비공개 URL 보존, 동영상 미재생, 메모리 기록 제한 테스트와 CRA 프로덕션 빌드 통과.
운영 배포나 실제 이미지 변환 요청/유료 설정 변경은 수행하지 않았습니다.
전체 npm run build(운영 사이트맵 조회 포함)는 실행하지 않았습니다.
