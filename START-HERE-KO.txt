ZIP의 수정 파일만 프로젝트의 같은 경로에 덮어쓴 뒤 커밋/푸시하세요.
SQL, 환경변수, 새 패키지 설치는 필요 없습니다.

- 기본 10명 보기
- 보기 버튼 10 / 20 / 25 / 50 / 100
- 선택 후보가 현재 페이지 밖이면 맨 아래에 추가 표시
- 예: 10명 보기, 내 후보 15등 → 11번째 줄에 실제 순위 15 표시
- 이미 현재 페이지에 있으면 중복 표시하지 않음
- 페이지 수와 기존 순위/정렬/필터 계산에는 추가 행을 포함하지 않음
- 검색 결과에서 제외된 후보는 추가로 표시하지 않음
- 기존 선택 후보 강조 표시 유지

이번 패치는 통계표 페이징만 변경합니다. v104 공개 범위 설정 기능을 추가하지 않습니다.
GitHub에 이미 있는 이미지 표시 방식은 그대로 둡니다.
기존 DOMPurify 설치 상태를 바꾸지 않습니다.
