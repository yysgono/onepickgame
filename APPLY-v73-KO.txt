v73 개인 목록 경량화 / 공개·비공개 SEO 분리 / 게시판 UI 번역

v72까지 적용된 프로젝트용입니다. 이번 ZIP은 v71/v72 수정 파일도 함께 포함합니다.

적용
1. Supabase SQL Editor에서 supabase/20261026_private_content_cards.sql만 새로 실행하세요.
   v71/v72 SQL을 이미 실행했다면 다시 실행할 필요 없습니다.
2. ZIP의 src, scripts 폴더와 server.js, vercel.json, community-seo-routes.cjs를 같은 경로로 덮어쓰세요.
   community-seo-routes.cjs는 프로젝트 최상위(server.js 옆)에 넣습니다.
3. npm run build 후 커밋·푸시·배포하세요. 새 빌드가 사이트맵도 재생성합니다.

개인 목록
- 내 퀴즈/티어표는 공개 홈 컴포넌트를 실행하지 않고 전용 경량 목록 사용.
- 본인 카드 12개 + 다음 페이지 유무 확인 1개만 DB에서 읽고 최대 12개를 반환.
- 브라우저에는 제목·제목 번역·썸네일 URL·개수·생성일만 전달.
- 전체 후보, 티어 배치, 문제, 정답, 설명, 추천 목록, 통계 요청을 개인 목록에서 제외.
- 메모리 내 현재 보이는 목록만 보관하며 localStorage에 큰 목록을 저장하지 않음.
- 썸네일은 지연 로딩. 실제 이미지 전송은 화면에 표시할 때 발생하며 0바이트가 되는 것은 아님.
- 개인 목록은 최신순이며 제목 검색은 DB에서 본인 전체 글에 적용.
- 카드에서 상세로 들어가 기존 편집/관리 기능 이용. 만들기 링크 유지.

검색 설정
- 내 월드컵 / quiz?mine=1 / tier-list?mine=1 / 건의사항 / 운영자 건의함 / 블로그 편집:
  서버 초기 HTML과 HTTP 헤더 및 React에 noindex 적용. 개인 응답은 private, no-store.
  개인 페이지의 SEO HTML 생성에는 실제 개인 DB 자료를 조회하지 않음.
- 공지사항 / 자유게시판: 초기 HTML에 고유 제목·목록·홈 링크·대표 주소를 넣고 index,follow 허용.
  공개 글 목록만 30초간 서버 메모리/CDN 재사용. 건의사항 내용은 공개 목록에 넣지 않음.
- Blog의 기존 공개 글과 색인 허용은 유지.
- 개인 페이지를 robots.txt로 새로 차단하지 않음. 로봇이 noindex를 확인하도록 허용.
- 기존 사이트맵의 /suggestions-board 항목 제거. 공지사항과 자유게시판 대표 주소 추가.
- 모든 언어에서 같은 글을 보여주는 자유게시판은 /en/community를 검색 대표 주소로 통일.
  /ko/community, /ja/community 등은 계속 각 언어 UI로 이용할 수 있음.
- 기존 메인 홈의 제목·설명·canonical은 바꾸지 않음.
  게시판은 게시판 고유 제목을 사용. 브랜드 검색에서 홈이 항상 첫 번째가 되도록 강제할 수는 없음.
- 검색에서 제외한 URL은 네이버/Google 보고서에도 색인 제외로 표시될 수 있음.
  검색 제외와 '진단 보고서에 제외 표시가 절대 없음'을 동시에 보장할 수는 없음.
- 사이트맵 URL은 그대로이므로 이미 등록했다면 의무적으로 재제출할 필요 없음.

번역
- 새 게시판의 작성/빈 목록/더보기/검색/카테고리/삭제/편집/답변 등 공통 UI를 16개 언어로 연결.
- 헤더 내 콘텐츠·프로필·로그인·Blog·언어 선택 문구와 내 콘텐츠 탭 번역.
- 사용자가 쓴 제목·본문·닉네임과 DB가 반환한 원본 오류 문구를 자동 번역하는 기능은 아님.
