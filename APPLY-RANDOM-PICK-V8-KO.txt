OnePickGame v8 — v7 이후 수정 파일

적용: v7까지 적용한 프로젝트를 백업하고 ZIP 파일을 같은 경로에 덮어쓴 뒤 새로 빌드/배포하세요.
추가 SQL이나 npm 패키지 설치는 없습니다. GitHub/운영 사이트에 직접 배포하지 않았습니다.

변경
- 추첨 확률/연출 안내 문구를 PC 17px, 모바일 16px로 확대.
- 돌림판 고정 확률 안내를 한국어 3줄로 나누고, %를 입력칸 바로 옆에 정렬.
  수동 확률 고정 및 ↺ 해제 기능은 그대로 유지.
- 슬롯을 홈/메뉴/언어별 SEO/사이트맵 목록에서 제거.
  기존 슬롯 주소는 카드뽑기로 영구 이동합니다. 기존 DB 데이터는 삭제하지 않습니다.
- PC 홈: 9개 게임을 3열로 배치. 넓은 PC에서도 4열로 바뀌지 않습니다.
  작은 화면은 가독성을 위해 2열을 유지합니다.
- 홈 카드 이미지 영역 310px, SVG 275px, 제목/버튼도 확대.
- 각 게임의 이미지/버튼/테두리를 같은 색 계열로 통일.
  배경은 아주 연한 색으로 낮추고 게임별 색상 구분은 유지.

검증: React production build, 9종 게임 UI, 기존 확률/후보 제외 규칙,
16개 언어 홈+게임 160개 서버 페이지, 슬롯 주소의 301 이동 검사 통과.
운영 DB 작업은 없으며 실제 브라우저 시각 검수는 미완료입니다.
