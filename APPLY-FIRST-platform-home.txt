종합 홈 문구·기존 카드 디자인·넓은 화면 카드 채우기 수정본

이 ZIP은 전체 프로젝트가 아닙니다. 프로젝트 루트에 같은 경로로 덮어쓰세요.
이전 홈 수정 ZIP 대신 이 수정본을 사용하세요. 이전 변경을 모두 포함합니다.

게임 순서: 월드컵 → 퀴즈 → 티어표 → 구절판 → 랜덤 뽑기
상단 ‘내 취향을 고르고, 만들고, 공유하세요’ 제목은 모든 언어에서 제외했습니다.
게임 선택 버튼에는 짧은 설명, 각 게임 제목 아래에는 두 문장 소개를 표시합니다.
게임 제목·섹션 소개문·카드 제목은 가운데 정렬합니다.
종합 홈에서만 헤더 게임 메뉴를 빼고 로고를 가운데 배치합니다.
로고의 사이트 이름을 홈의 단일 H1로 사용합니다.
본문은 최대 1800px로 가운데 배치해 양옆 여백을 둡니다. 기존 카드 크기는 유지합니다.
게임 선택 박스 바로 아래에 20개 언어 선택을 추가했습니다.
섹션 제목 바로 옆에 전체보기 버튼을 두고 제목·소개문 글씨를 키웠습니다.
가로 스크롤바는 숨기고 화살표 버튼 또는 터치로 넘깁니다.
화면이 넓으면 필요한 카드를 더 읽고, 옆으로 넘길 때 다음 페이지를 이어 읽습니다.
월드컵은 기존 후보 소개·후보 수·플레이 수·날짜·버튼 디자인을 사용합니다.
퀴즈는 기존 카테고리 카드와 같은 이미지·문제 수·플레이 수·지금 풀기 버튼을 사용합니다.
티어표는 프리셋에 설정한 제목을 우선하며 홈에서 조회수는 표시하지 않습니다.
티어표 목록과 홈은 같은 TierCardPreview 컴포넌트를 사용합니다.
설명·버튼·카드 문구는 20개 언어를 지원합니다.
모든 새 JS/CSS 파일을 함께 적용하세요.

홈 API가 없는 환경에서도 기존 공개 DB 연결로 카드를 불러오도록 수정했습니다.
src/seo/platformHomeData.js, src/utils/publicSupabaseConfig.js,
src/utils/publicPlatformHome.js와 함께 포함된 supabaseClient.js도 적용하세요.
로컬에서는 개발 서버를 다시 시작하고 새로고침하세요.

새 한국어 월드컵 목록: /ko/ideal-type-world-cup
새 영어 월드컵 목록: /en/ideal-type-world-cup
기존 /ko와 /는 다섯 게임을 소개하는 종합 홈입니다.

기존 개별 콘텐츠 URL·원본 월드컵 ID·후보 연결을 유지합니다.
20개 언어의 새 목록 주소·소개문·메타정보·사이트맵 생성을 반영했습니다.

프런트엔드와 server.js/vercel.json을 함께 배포해야 합니다.
기존 npm run build가 사이트맵과 seo-shell.html도 다시 생성합니다.
새 SQL 실행이나 DB 이전, 새 환경변수 설정은 필요하지 않습니다.

운영 사이트에는 아직 배포하지 않았습니다.
