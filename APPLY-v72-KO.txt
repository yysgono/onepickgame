v71 적용 후 사용하세요. v71 기능/수정 파일도 포함한 누적 ZIP입니다.
1. Supabase SQL Editor에서 supabase/20261026_community_updates.sql만 실행하세요.
   v71 SQL을 아직 적용하지 않았다면 20261026_community_blog.sql을 먼저 실행해야 합니다.
2. src, scripts, server.js, vercel.json을 동일 경로에 덮어쓰세요.
3. npm run build 후 기존 방법으로 배포하세요.

사용법
- Blog 글 상세페이지: 운영자에게 '글 수정' 옆 '글 삭제' 표시.
  삭제 확인 후 현재 언어 글만 삭제합니다. 같은 주소의 다른 언어 글은 유지됩니다.
- 내 콘텐츠의 내 월드컵: 처음 12개, 더보기로 다음 12개. 검색도 DB에서 내 글 전체에 적용.
  전체 월드컵 목록 선조회 제거, 후보 전체 데이터 대신 카드에 필요한 제목/이미지 주소만 조회.
  퀴즈/티어표 내 콘텐츠의 기존 페이징은 유지합니다.
- 건의사항: DB 저장. 작성자 본인과 운영자만 열람. 일반 회원은 다른 사람의 글을 읽을 수 없습니다.
- 운영자 건의함: /ko/admin-suggestions (다른 언어에서도 동일).
  프로필 메뉴 또는 건의사항 페이지의 '운영자 건의함 열기'로 접근합니다.
  운영자는 모든 언어 건의사항을 읽고 답변할 수 있습니다. 작성자는 자신의 건의사항 페이지에서 답변 확인.
- 예전 건의사항은 각 사용자의 localStorage에만 저장되던 데이터입니다.
  다른 사용자 컴퓨터의 옛 글을 운영자 서버에서 복구할 수 없습니다. 새 버전부터 서버에 전달됩니다.
  기존 브라우저 데이터는 삭제하지도, 자동으로 업로드하지도 않습니다.
- 자유게시판: 언어와 무관하게 같은 전체 목록. 전체/자유/월드컵/퀴즈/티어표/랜덤 뽑기 탭.
  글쓰기에서 카테고리와 원문 언어 선택. 제목 아래에 작성자 닉네임·원문 언어·분류·날짜 표시.
  닉네임은 서버에서 실제 profiles 값으로 설정하고 기존 글도 보완합니다. 이메일은 공개하지 않습니다.
- 공지사항: DB에서 발행권자만 작성 허용. 글쓰기에서 발행 언어 선택.
  한국어 페이지는 한국어 공지, 영어 페이지는 영어 공지를 보여줍니다.
  번역 글은 각 언어로 직접 작성하며 자동 번역은 제공하지 않습니다.

검증
PGlite 모의 DB: SQL 재실행, 일반 회원 Blog 삭제/공지 작성 차단, 언어별 Blog 삭제,
작성자 닉네임 위조 차단, 건의함 다른 사람 글 열람/사칭/답변 차단, 운영자 조회/답변,
내 월드컵 12/12/2 페이징·검색·소유권 분리 확인.
JSX/JS/CSS 및 배포 경로 정적 검사 통과. 실제 운영 DB·전체 CRA 빌드·브라우저 시각 검증·배포는 미실행.
