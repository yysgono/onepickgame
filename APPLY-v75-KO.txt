원픽게임 v75 — 홈 첫 표시 및 목록 로딩 개선

적용 기준: 직전에 제공한 v74 통합 휴지통 수정본까지 적용한 프로젝트.
v74를 아직 적용하지 않았다면 해당 ZIP의 SQL과 적용 안내를 먼저 진행하세요.
이번 v75 자체에는 추가 SQL이나 새 패키지가 필요하지 않습니다.

적용:
1. 이 ZIP의 파일을 같은 경로에 덮어쓰세요.
2. 새로 빌드하고 배포하세요. 예전 build 폴더를 그대로 올리지 마세요.
3. 애드센스 실험은 변경하지 않아도 됩니다.

변경:
- 외부 Google Fonts CSS가 첫 화면 표시를 막지 않도록 비동기 적용.
- font-display:optional로 늦은 폰트 교체에 따른 위치 변화를 완화.
  느린 연결에서는 해당 방문 동안 시스템 대체 폰트가 보일 수 있습니다.
- 월드컵 홈에서 첫 목록을 기다리는 동안 카드 높이에 맞춘 정적인 로딩 틀 표시.
- 완료된 빈 카테고리 또는 조회 실패에는 틀을 유지하지 않음.
- 홈 소개 줄바꿈을 세로 방향으로 정리하고 서버 소개에도 동일한 문장 구분 적용.
- 제목/설명/인기 월드컵 링크와 기존 게임 동작 유지.
- 추가 DB 조회, 다음 페이지 선조회, localStorage 저장을 추가하지 않음.

검증:
- React 프로덕션 빌드 성공.
- 기존 홈 페이징 검사 통과(숨겨진 다음 페이지 조회 방지 포함).
- 홈 SEO 삽입/이스케이프/캐시 검사 및 실제 서버 미들웨어 16개 언어 검사 통과.
- 실제 광고가 표시되는 모바일 브라우저 및 운영 배포에서 측정하지는 않았습니다.
- 사이트맵 생성에 운영 DB가 필요한 전체 npm 빌드 과정은 실행하지 않았습니다.

한계 및 배포 후 확인:
- 이번 변경은 확인된 지연·밀림 후보에 대한 1차 개선이며 CLS 정상화 보장은 아닙니다.
- 서버 홈 셸과 React 전체 헤더/목록을 완전히 동일하게 만드는 SSR 전환 작업은 아닙니다.
- 자동광고가 나중에 만드는 공간이나 다른 페이지에서의 밀림까지 해결하지는 않습니다.
- 비로그인 모바일에서 홈을 열어 목록 로딩, 검색, 더보기, 오류 재시도를 확인하세요.
- 같은 조건의 PageSpeed 테스트를 2~3회 비교하고 레이아웃 변경 원인을 재확인하세요.
- 실제 방문자 보고서는 최근 28일 데이터를 사용하므로 곧바로 바뀌지 않습니다.
- 기존 파일을 별도로 보관하면 이번 ZIP의 동일 파일만 되돌려 취소할 수 있습니다.
